# Release Note

## Important Changes

### Distribution & Logic Layer

- Manager processes corresponding maps before broadcasting Monitor, Filesystem, and OSD map updates to modules, ensuring modules can read updated state when notified. [commit](https://github.com/ceph/ceph/commit/e4be3edfcd75368979b084746ee5093712d2a494)
- dmClock server skips clients with pending requests during cleanup, avoiding clearing scheduling state with outstanding requests. [commit](https://github.com/ceph/ceph/commit/16b8eb315090d9714730669a74eeb726f1a0a04f)
- OSD adds degraded PG recovery sleep configuration to throttle data recovery movement for degraded PGs by HDD, SSD, and hybrid types. [commit](https://github.com/ceph/ceph/commit/ccf513fa0cf56845fad1a8f7059b85345dae7ed4)
- During Monitor election, record pending peer pings and process them after election completes, to handle pings when quorum feature is not yet established. [commit](https://github.com/ceph/ceph/commit/f8aac3c743c8d006507ab2bac715700e9d07060a)
- MDS skips duplicate acquisition when request already holds target inode write lock, avoiding repeated acquisition of the same lock in one request. [commit](https://github.com/ceph/ceph/commit/375c29537e78d758f74a0366a2b27ed021a34d2b)
- Add command to force disable always-on Manager modules, requiring explicit confirmation; module disabled state is stored in MgrMap. [commit](https://github.com/ceph/ceph/commit/ba3bb8d290738a7ebee1c0808d0fcc6211d01da7) [commit](https://github.com/ceph/ceph/commit/62c7f3dfd7f4fec5262f1cec5f2c978014b4cbee)
- OSD adds clear_shards_repaired admin command to reset repaired shard count to zero or set to specified value, to clear or re-trigger OSD_TOO_MANY_REPAIRS alert. [commit](https://github.com/ceph/ceph/commit/69e75cd622bf013be095f50224bdb6fbed0cf7ca)
- Fix importer session cleanup and client state handling after MDS export subtree interruption, supplement importing session count, and avoid race condition caused by checks before journal commit. [commit](https://github.com/ceph/ceph/commit/f08a263a2e299a2b3721fdef93300e62af2eefde) [commit](https://github.com/ceph/ceph/commit/a138a435192c9d4be9c059aad892f39cc9c445cd) [commit](https://github.com/ceph/ceph/commit/7fcd63fa0889f69805d77fb2fcdf55437514cbe6) [commit](https://github.com/ceph/ceph/commit/626f3a78cadffc07cbfd74adc042f1f002b7c210) [commit](https://github.com/ceph/ceph/commit/a25e87292d11612633c9e5fa9066a1a773db6c6e) [commit](https://github.com/ceph/ceph/commit/e9d3225babc19aece406c1c72438572f1a51a5ed)
- CephFS filesystem rename requires filesystem to be offline and refuse_client_session to be set; command returns clear error message. [commit](https://github.com/ceph/ceph/commit/c3f632044c9e68aad6f7e1cd4284a8862afdf572) [commit](https://github.com/ceph/ceph/commit/3a8046c3be8969aee04c612094194173b7dbe1ce)
- MDS no longer fast-dispatches client metrics messages, but processes them through normal message dispatch path. [commit](https://github.com/ceph/ceph/commit/b6f39f6f86784c23ae3cee52d4b5efd57e8992ff)
- MDS session tracker includes sessions in opening and killing states in load statistics. [commit](https://github.com/ceph/ceph/commit/3ed812e51b02ebbf93e964969cd2579bbb00a463)
- Exporter handles daemon metric parsing failures to avoid abnormal input interrupting collection process. [commit](https://github.com/ceph/ceph/commit/6a6b85033a30e87a57b3295b809d72a22804b4c4)
- Add mon disable_stretch_mode command to exit stretch mode and restore regular pool settings after explicit confirmation; can specify new CRUSH rule, documentation and QA updated accordingly. [commit](https://github.com/ceph/ceph/commit/6f571d38ae1b131d8d18668e8dee243115d1f40c) [commit](https://github.com/ceph/ceph/commit/85e8927e78cb5ff90da339c46241aa0a7a75fb39) [commit](https://github.com/ceph/ceph/commit/f01ec39cd9152d5d6b09146229c0ee6d57b74f47) [commit](https://github.com/ceph/ceph/commit/9a775a1c90d3651f49d19cdb52ceb662c9cf752c) [commit](https://github.com/ceph/ceph/commit/aff4dba9ad40823f660ace2063f0131dfbaedbd8)
- MDS discards client metrics messages in recovery state. [commit](https://github.com/ceph/ceph/commit/b05f9ba13e8764322b2dde860de8e34be5897ad3)
- SimpleLock's has_any_waiter uses WAIT_ALL mask corresponding to lock type to check waiters, skipping read lock waiters. [commit](https://github.com/ceph/ceph/commit/0199784ab931d02e1a704ab4676bf1a3442dac97)
