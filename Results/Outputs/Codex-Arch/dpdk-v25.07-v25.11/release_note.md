# Release Note

## Important Changes

### Poll-Mode Drivers (PMDs)

- GVE DQO publishes the maximum number of data descriptors allowed per MTU-sized packet segment to ethdev, and counts transmitted packets exceeding the hardware limit. [commit](https://github.com/DPDK/dpdk/commit/f4a70b449bfac5343bf498f4132d5b8da4b0a885)
- DPAA bus adds FMan device node parsing and management, and adjusts network configuration reading and NIC initialization to use this node information. [commit](https://github.com/DPDK/dpdk/commit/0095306cdbda8e576252cbdc260c290cd96b3bac)
- DPAA PMD adds a devarg to allow received error packets to be sent to the main Rx queue, and explains the configuration method in the NIC guide. [commit](https://github.com/DPDK/dpdk/commit/5cea57f804058d245e41bd8320a4075ba78cf889)
- DPAA2 ordered queues add software taildrop handling, dropping packets when queue backlog reaches the limit while maintaining queue order management. [commit](https://github.com/DPDK/dpdk/commit/0d2ffac0f6bb6d0a979a17d285f303c7076b4497)
- AF_XDP PMD adds XDP program attachment mode configuration, allowing selection of the driver-supported attachment method and creating sockets accordingly. [commit](https://github.com/DPDK/dpdk/commit/41756f243f46c769886accae308478303d3252d1)
- Reorganize the mapping of VMBUS devices to functional interfaces, and synchronously adjust netvsc's calls to channels and device functions. [commit](https://github.com/DPDK/dpdk/commit/303f92849714c00f7d2a9f8f1400eb43d0344df5)
- ZXDH PMD adds a VLAN TPID setting interface, allowing configuration of the protocol identifier in VLAN tags and sending it to the device. [commit](https://github.com/DPDK/dpdk/commit/a13c5490193002dcfb60935da29f880cdef95620)
- ZXDH PMD adds I510/I511 physical function device identification and initialization, supporting device operations for corresponding PF models. [commit](https://github.com/DPDK/dpdk/commit/752ebb371ded7eec4ccdfc192d1c9475039df9a9)
- NULL PMD adds fast mbuf release Tx offload support, returning packet buffers in batches along the transmit completion path. [commit](https://github.com/DPDK/dpdk/commit/675ddc233d68d90b3858cdb6267dd407c4e85984)
- ethdev adds a 800 Gbit/s link rate flag, and synchronously updates rate parsing, testpmd commands, and functional tests. [commit](https://github.com/DPDK/dpdk/commit/b671608495d95b2b51487bdb8f5f4b32ca5c7d99)
- GVE PMD adds a data-plane-specific log category, allowing DQO Rx/Tx paths to output debug information separately. [commit](https://github.com/DPDK/dpdk/commit/74bfd4b804d274dd3b6402015e8370b42a292a85)
- GVE DQO Tx path supports out-of-order completion, associating completed transmit descriptors with original packets via completion identifiers. [commit](https://github.com/DPDK/dpdk/commit/5fd289ff3a008370befef95029b9b65b66661217)
- GVE DQO Rx path supports out-of-order completion, tracking completed receive buffers by completion identifier and reclaiming corresponding queue entries. [commit](https://github.com/DPDK/dpdk/commit/1aed73b23ac04690e586fc36126cdffaf92e1063)
- NETVSC configures queues and memory based on the NUMA node of the VMBUS device, and explains NUMA settings in the NIC guide. [commit](https://github.com/DPDK/dpdk/commit/311d3e9ad0b1ba7ce35aded08853af50440b1122)
- ZXDH PMD adds low-level flow table operation implementation, providing interfaces for subsequent flow API creation and management of hardware table entries. [commit](https://github.com/DPDK/dpdk/commit/43a9a4ddada8156b3b560d81d04cfe414ccd616d)
- ZXDH PMD adds rte_flow API, implementing flow rule parsing, validation, and hardware table entry configuration, and updates functional documentation. [commit](https://github.com/DPDK/dpdk/commit/d0af48c1b9525894a8f12895ee62f0bcaf70bc7c)
- XSC PMD adds a firmware version query interface, which can retrieve and return the NIC firmware version via device information. [commit](https://github.com/DPDK/dpdk/commit/cf1bc37f183eeb0a0310bb0ff0d3f804ad1d5fcb)
- XSC PMD adds TCP segmentation offload support, generating TSO contexts as configured and correctly submitting transmit descriptors. [commit](https://github.com/DPDK/dpdk/commit/7bd566e1e920ee0f94bd81810362cb5ac7ccc4ec)
- XSC PMD adds an optical module EEPROM read interface, allowing dumping of module information for ethdev diagnostics. [commit](https://github.com/DPDK/dpdk/commit/53b2c2cbe0252cf6f42c79e398698c8fb5c7a562)
- XSC PMD adds promiscuous mode setting, configuring reception of packets with non-local destination MACs via device flow tables. [commit](https://github.com/DPDK/dpdk/commit/c74dc3cf359034e74a09eb7482b28121b5cd9500)
- XSC PMD adds link status query, reading current link connection status from the device and updating ethdev link information. [commit](https://github.com/DPDK/dpdk/commit/b2cbd3ac0338afeffe31179173c4db26096a3728)
- XSC PMD adds link status event handling, notifying ethdev and refreshing port status upon hardware link changes. [commit](https://github.com/DPDK/dpdk/commit/433506e676031ac84f1dc9057652510c309a972a)
- XSC PMD adds FEC mode query and set interfaces, allowing reading of current forward error correction mode and configuring supported modes. [commit](https://github.com/DPDK/dpdk/commit/4a586179cc19324483a3f12b7ca19a294a223521)

- iavf scalar Tx path adds QinQ VLAN double-tag insertion offload, and updates driver feature declarations. [commit](https://github.com/DPDK/dpdk/commit/fdc37964c2bfbf769c469636ca5f19efa7ab4cd0)

- i40e identifies GTP as a UDP tunnel type, allowing related packets to be processed via the UDP tunnel receive path. [commit](https://github.com/DPDK/dpdk/commit/cdebcc490f6a476755ab3c6726f86105ed90f0b3)
