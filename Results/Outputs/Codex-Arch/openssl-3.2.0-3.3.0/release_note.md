# Release Note

## Important Changes

### Protocol Layer (SSL/TLS/DTLS/QUIC)

- Check for null before dereferencing connection object in SSL control operations to avoid crashes on invalid control calls. [commit](https://github.com/openssl/openssl/commit/24844be16f0e4c30ae3386760ff571592b14b02f)
- Validate both SSL and connection pointers in internal control dispatch to protect null object call paths. [commit](https://github.com/openssl/openssl/commit/b9788ce6a869185f040df4c98d2e7143110aa517)
- Added null pointer checks for SSL and connection objects to avoid control operations accessing uninitialized connections. [commit](https://github.com/openssl/openssl/commit/b419fccad7e88ff3d7c9fd74b2990952dd09b57a)
- Confirm internal connection validity before executing SSL control operations to prevent null connection dereference. [commit](https://github.com/openssl/openssl/commit/8dc82c02559545fabe15fd95d55623f4f7fc0f08)
- No longer append stream-related frames after implicit-length STREAM frames, respecting the termination position requirement of frame encoding. [commit](https://github.com/openssl/openssl/commit/7fe3010471a3263b2469ae35589357089050ce62)
- When sending QUIC stream data, synchronously deduct connection-level flow control credit to prevent total across streams exceeding `MAX_DATA`. [commit](https://github.com/openssl/openssl/commit/e57bf6b3bfa2f0b18e5cad7fd3c5fdd7c51516b9)
- Added QUIC stream receive timer manager (SRTM) to schedule read timeouts and delayed processing based on received stream data. [commit](https://github.com/openssl/openssl/commit/abc06d53a968f9072a2d026a776f3b66944ae7f3)
- Added `SSL_OP_PREFER_NO_DHE_KEX` option so server can prefer key exchange without DHE in PSK handshake. [commit](https://github.com/openssl/openssl/commit/b8590b2f365a963965d799c438c5c92659c2fcae)
- Added QUIC SRT data generator to produce reproducible traffic and event sequences for receive stream timer tests. [commit](https://github.com/openssl/openssl/commit/2db3fdb4578ca43624acda81b72bc02b08c8ce3a)
- Added QUIC local connection ID manager to track generation, publication, and retirement status of local connection IDs. [commit](https://github.com/openssl/openssl/commit/8489a0a1f246e2f8bb1d98fc550b7a0fd341ef51)
- Added fuzzing for QUIC local connection ID manager, covering ID updates and abnormal sequence inputs. [commit](https://github.com/openssl/openssl/commit/3d7f83ebdca1d66f7ddb2ad1d23866d3a6c4e3cf)
- Added debug logging for QUIC local connection ID manager to facilitate tracking ID allocation and retirement. [commit](https://github.com/openssl/openssl/commit/1f2958536eff61984b4746410cd3e4fe8f0383dd)
- Fixed strict-aliasing violation in NIST big number little-endian optimization to avoid compiler optimization causing calculation errors. [commit](https://github.com/openssl/openssl/commit/e8e95f20a9b00ca62d407263110663eba7614683)
- Fixed memory leak when creating CMS signed receipt request. [commit](https://github.com/openssl/openssl/commit/154131da112ed28b619dc6a7a0bec255e2a79316)
- Added lock for `CRYPTO_secure_used()` to ensure data consistency when concurrently querying safe heap usage. [commit](https://github.com/openssl/openssl/commit/f76710122599731dd9e023f9786b0f3f8863db25)
- Fixed issue in CMAC test releasing alias pointer to avoid double free of same object. [commit](https://github.com/openssl/openssl/commit/167e5f34c8f4e7c414c6e48376987160bc23c7df)
- Make `openssl list` handle providers that do not provide parameter table, avoiding misjudging legitimate empty table as error. [commit](https://github.com/openssl/openssl/commit/a4be37b8ce8ed4cc809b45c0177cb47670ed4224)
- Added QUIC local connection ID manager to track generation, publication, and retirement of local connection IDs. [commit](https://github.com/openssl/openssl/commit/0df897321dc146e7ece7b23516cf24b5975f9dc0)
- ENGINE cipher path no longer sets provider-specific parameters to avoid incompatible calls. [commit](https://github.com/openssl/openssl/commit/f61a37d17bae26133765018b1370078d4de14cbe)

### Provider and Engine Framework

- Added vector implementation for RISC-V AES based on Zvkned, using standard vector crypto instructions for AES block transformations. [commit](https://github.com/openssl/openssl/commit/f6631e38f901e2a439604fac2bd62933f9dbb8ad)
- Added vector implementation for RISC-V SM4 based on Zvksed, using vector crypto extensions for SM4 round function. [commit](https://github.com/openssl/openssl/commit/7543bb3a69c021edbe73bb38a8cc4d3708a68c5d)
- Added AES-192 support for RISC-V vector crypto implementation, extending hardware path to 192-bit key length. [commit](https://github.com/openssl/openssl/commit/94474e02fa217c037ece9d819a9b12025f65cdb9)
- Provided vector AES-CTR implementation for RISC-V to accelerate counter mode encryption and decryption. [commit](https://github.com/openssl/openssl/commit/18ed3a58b01f8f1affdedced1f4f62447b7df9f9)
- Added vector AES-GCM implementation for RISC-V, using vector AES and GHASH for authenticated encryption. [commit](https://github.com/openssl/openssl/commit/d056e90ee58a039263b843e8fa330fa71b4d4835)
- Added AES-GCM test vectors covering more input lengths, AAD, and tag combinations. [commit](https://github.com/openssl/openssl/commit/ebecf322e52bf3cabaf36335c138712ae658503f)
- Provide AES-128/256-XTS vector implementation for RISC-V for data sector encryption. [commit](https://github.com/openssl/openssl/commit/3e56c0efe72aad6d4246149d9461af48072b681b)
- Provide vector AES-ECB implementation for RISC-V, using vector instructions to process independent AES blocks. [commit](https://github.com/openssl/openssl/commit/751a22194e4dc52532d2aedd49fe62dbea0badc8)
- Implement BLAKE2s provider using shared macros, reducing duplicate algorithm registration code with BLAKE2b. [commit](https://github.com/openssl/openssl/commit/6d1e730a1ea2c64bdffa88c6b3bee4c3f5bed602)

- Add known-answer tests for KBKDF using KMAC128, verifying KDF output matches standard vectors. [commit](https://github.com/openssl/openssl/commit/3cb0755323281267211fbe951b94a2552e99d32a)
