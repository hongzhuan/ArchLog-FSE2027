# Release Note

## Important Changes

### Core Storage Engine Layer

- KernelDevice creates multiple asynchronous discard workers according to `bdev_async_discard_threads` configuration, and stops and recycles these threads when the device is closed. [commit](https://github.com/ceph/ceph/commit/91b0fe4d51cebb5667f3e58093ecc1346071f1f0)
- BlueStore adds health warnings for slow operations and stalled reads: counts warnings per device within a configured time window, reports in health detail after reaching `bdev_stalled_read_warn_threshold`, and allows configuring the statistics duration and threshold. [commit](https://github.com/ceph/ceph/commit/fff1105ab82fcae5a3ecc383006cf94d4dd4e06e)
- Added `osd pool stretch show/set/unset` command for stretch pool to query, configure, or cancel bucket count, target, barrier, CRUSH rule, size, and min_size. [commit](https://github.com/ceph/ceph/commit/072b08eddccd4654d42b1d65b36ed4d3f12c126c)
- As long as an MSR rule exists in the CRUSH map, even if no pool currently uses that rule, `CRUSH_MSR` is included in the client minimum compatible feature requirement. [commit](https://github.com/ceph/ceph/commit/c275ad87e7a48bb68fa36991ed23e72898eeff9c)
- Fixed allocmap repair logic when BlueStore multi-label replicas conflict with BlueFS regions, so device label positions are correctly updated according to valid replicas. [commit](https://github.com/ceph/ceph/commit/7570b3423b472f109910bc05baf9864180856240)
- mClock adds measured IOPS lower thresholds for HDD and SSD respectively; if the baseline is below the lower limit or above the upper limit, the current or default capacity value is retained, and abnormal measurements are not used for QoS capacity settings. [commit](https://github.com/ceph/ceph/commit/bca9920b003f5dd1bdb431ac76071756dc008ee1)
- Fixed RBD reusing a closed SSL stream on reconnection during HTTPS import migration; resets the stream before each reconnection and adds HTTPS migration coverage. [commit](https://github.com/ceph/ceph/commit/c7d197520c383314de6091c888a26e575ce972d5)
- When object map is inconsistent or invalid, RBD flatten falls back to default object existence determination, avoiding skipping objects based on erroneous object map and causing data corruption. [commit](https://github.com/ceph/ceph/commit/5d5ea4e159612728db441072bec62599b9aa534a)
- Fixed CephFS low-level read/write concurrency issue: holds `client_lock` during file handle check, and limits single length to `INT_MAX` before read/write, avoiding race between check and I/O and return length overflow. [commit](https://github.com/ceph/ceph/commit/4da7257c61d762d87dd12e4c35ffbb20a8858766)

### Management and Control Layer

- cephadm triggers redeployment when the set of daemons a service depends on changes, and reselects daemon images to apply dependency changes. [commit](https://github.com/ceph/ceph/commit/844d02a5553d5618f1eda2341cf5c4456e7935cf)
- cephadm ingress HAProxy listen default address changed to IPv6 wildcard address `[::]`, so frontends without a specific VIP receive both IPv4 and IPv6 traffic. [commit](https://github.com/ceph/ceph/commit/8d96c387102adf6773fc4098b39aa43ebae15b3c)
- Dashboard NVMe-oF service form adds mTLS toggle; when enabled, requires Root CA certificate, and generates service configuration with NVMe-oF group/pool changes. [commit](https://github.com/ceph/ceph/commit/8f055c18fc859706f99d8d1b2fff5ddd4f27fc77)
- CephFS subvolume adds optional earmark metadata, assignable at creation or managed via earmark get/set/clear, used to mark associated services like NFS, SMB. [commit](https://github.com/ceph/ceph/commit/480bc61ed3cf2323c2a56bcfd357775984c35358)
- cephadm-generated Ceph, init-container, and sidecar systemd units change Docker dependency from `Requires` to `Wants`, so Docker Engine restart no longer forcibly stops container services, supporting Docker Live Restore. [commit](https://github.com/ceph/ceph/commit/f882fa82fa1bac9d1c8743e2b0d2f654cf9afbb7)
- Added `PUT /rename-path` to Dashboard CephFS REST API to rename a file or directory from source path to target path. [commit](https://github.com/ceph/ceph/commit/0828906a1b2a1c6773c6d3b0bf3777d88b1609f4)

### Service and API Layer

- CephFS mirror incremental sync uses snapdiff API to get directory entry differences between two snapshots, and applies additions, deletions, or changes based on differences, avoiding per-directory comparison of the entire tree. [commit](https://github.com/ceph/ceph/commit/8cb960e9760df587015c43a46ea550946cc86a12)
- Added radosgw-admin realm default rm command to delete current default realm ID configuration, and returns error on deletion failure. [commit](https://github.com/ceph/ceph/commit/e352264128ed15dbf89338859d68cc4697870663)
- When rgw_realm is not explicitly configured and the default realm has no default zone, RGW ignores the realm without a zone and attempts to load the global default zone. [commit](https://github.com/ceph/ceph/commit/358a197370b8ce527e28800246003d3e6c00027d)
- Optimized RGW bucket object listing: when caller does not request namespace objects, skip consecutive namespace entry ranges in the index, reducing item-by-item scanning. [commit](https://github.com/ceph/ceph/commit/8f8cc9a57b17621cdaec2c8a995f5850b362dc52)

### Infrastructure Layer

- ceph-volume adds optional TPM2 token enrollment for LUKS2 encrypted OSDs; `--with-tpm` and OSD spec's `tpm2: true` can register TPM2 unlock token in LVM/raw deployment paths. [commit](https://github.com/ceph/ceph/commit/73e9c6ce45be1b1d990b530e5639e0aa2c003e01)
- Fixed `ceph-bluestore-tool` command-line parsing, added confirmation option definitions for dangerous commands, and disabled option name prefix guessing, requiring full input of confirmation parameters. [commit](https://github.com/ceph/ceph/commit/bc0f0897ce1d1451258d6c32b6ca80361cfe1cc7)
- Changed ISA-L erasure-code library to be configured, compiled, and installed as a PIC static library via CMake `ExternalProject`, exporting unified `ISAL` target for plugin linking. [commit](https://github.com/ceph/ceph/commit/d199d369746f8de62caab726de5fec2aa4477616)
- Stable branch merge commit updated CMake and Debian package version markers to 19.1.1. [commit](https://github.com/ceph/ceph/commit/e01d26d122498cd8e79de9811a8497d7c4a56559)
