# Release Note

## Important Changes

### API & Integration Layer

- Adds jemalloc hook module, centrally maintaining application-registered allocator callbacks and their invocation states. [commit](https://github.com/jemalloc/jemalloc/commit/5ae6e7cbfa6d6788340cc87d7717548f4d7960fe)
- Adds fast return branch when no hooks are registered, avoiding function dispatch overhead for checking callbacks in common allocation operations. [commit](https://github.com/jemalloc/jemalloc/commit/fe0e39938593b5fb16dc09fcdbe29d6ad7b3cf05)
- Adds experimental.hooks.install/remove mallctl commands for runtime installation or removal of allocator hooks, and adds API tests. [commit](https://github.com/jemalloc/jemalloc/commit/bb071db92ee8368fb6e64ef328d49fae6ba48089)
- Adds hook exhaustion test, verifying that installing new hooks after callback slots are full fails as expected and existing hooks remain effective. [commit](https://github.com/jemalloc/jemalloc/commit/59e371f46331a3f4b688d6622a0af7ccc4f96be6)
- Adds opt.huge_threshold, placing objects exceeding the configured size into a dedicated huge arena to isolate large object allocation and deallocation. [commit](https://github.com/jemalloc/jemalloc/commit/94a88c26f4d9cffd884a349201e7605f13495f3f)
- Startup initialization adds MALLOC_CONF dynamic slab size parsing, allowing adjustment of slab size for small allocations via environment configuration. [commit](https://github.com/jemalloc/jemalloc/commit/5112d9e5fd2a15d6b75523a3a4122b726fbae479)
- TSD nominal state adds fork child process support, rebuilding or cleaning up inherited thread state lists after fork. [commit](https://github.com/jemalloc/jemalloc/commit/41b7372eadee941b9164751b8d4963f915d3ceae)
- configure detects whether readlinkat is available, making runtime path resolution prefer the directory-relative symlink interface. [commit](https://github.com/jemalloc/jemalloc/commit/e8ec9528abac90efe4e0cc3a29da8d7aea59f23d)
- Adds experimental smallocx(size, flags) API, using flag parameters to control small object allocation behavior and declaring the interface in configuration. [commit](https://github.com/jemalloc/jemalloc/commit/08260a6b944a67a3d9f63e7eb738718fc760e0ea)
- Supports splitting a bin into multiple shards within one arena, reducing contention on the same bin lock for small object allocations. [commit](https://github.com/jemalloc/jemalloc/commit/37b89139252db18c95ebce3e0eac67817fa4a8ab)
- Adds opt.bin_shards configuration item to set the number of bin shards per arena, allowing concurrency adjustment based on load. [commit](https://github.com/jemalloc/jemalloc/commit/3f9f2833f6228e07673d75c9bce6f5fb58c5f3b0)
- Allows setting oversize_threshold to a low value to disable the oversized arena allocation feature, uniformly using normal arenas to manage objects. [commit](https://github.com/jemalloc/jemalloc/commit/788a657cee745c1f827ddf1db50d580bd5e4347b)

### Profiling & Statistics Layer

- Adds mallctl query interface and stats output for opt.huge_threshold, reporting the current large object threshold configuration. [commit](https://github.com/jemalloc/jemalloc/commit/1302af4c43e031304b422e36fcbb9e159804e0ac)
- Sampling allocation path adds internal log recording, outputting allocation sizes and arena information that trigger profiling sampling. [commit](https://github.com/jemalloc/jemalloc/commit/b664bd79356d7f6da6f413023f9aef014b85c145)
- Adds unit tests for the log module, verifying configuration filtering, formatted content, and log callback output. [commit](https://github.com/jemalloc/jemalloc/commit/5e23f96dd4e4ff2847a85d44a01b66e4ed2da21f)
- mallocstats output adds per-arena extent usage information, and the manual explains the relationship between extents and allocation statistics. [commit](https://github.com/jemalloc/jemalloc/commit/c14e6c08192034d9140d61197d7c4981ca293610)
- Adds extent_avail heap current byte count statistics and mallctl documentation, reporting the total free extents available for allocation. [commit](https://github.com/jemalloc/jemalloc/commit/126252a7e6bd098d649f6a82a947c7c056816c2c)
- Adds mallctl and stats output for arenas.bin.i.nshards, reporting the number of bin shards per arena. [commit](https://github.com/jemalloc/jemalloc/commit/45bb4483baef0f9bb1362349d9838ee041c42754)
- Statistics output adds rate fields for mutex counters, reporting unit-time changes in lock wait and contention events. [commit](https://github.com/jemalloc/jemalloc/commit/36de5189c70fee959ebcdfadd8dfa374ff430de5)
- Moves huge_threshold functionality out of the experimental mallctl namespace, providing it as a formal configuration interface. [commit](https://github.com/jemalloc/jemalloc/commit/7a815c1b7c796ef35e7ede60cb2dd44aba9626b4)

### Cross-cutting / Other Architecture-related Changes

- Atomic operation library adds atomic_u8_t type, and forces inline of 8-bit atomic read/write functions to reduce call overhead. [commit](https://github.com/jemalloc/jemalloc/commit/e74a1a37c82fa3a44cee1002d9d8957bcc8274a7)
- TSD adds global slow path state, allowing threads to enter global synchronization handling from the fast local path during initialization or state transitions. [commit](https://github.com/jemalloc/jemalloc/commit/e870829e645bfd6d54e4a2d4cacce39478216a1e)
- Adds Seq module implementing a simple seqlock, providing internal synchronization primitives for writer update sequences and reader lock-free retry reads. [commit](https://github.com/jemalloc/jemalloc/commit/06a8c40b36403e902748d3f2a14e6dd43488ae89)
- Added the lg_ceil function to bit_util, which calculates the smallest power exponent of 2 that is greater than or equal to the given value. [commit](https://github.com/jemalloc/jemalloc/commit/2f07e92adb7060045e9e8601126e5ec071091c42)
- SC module adds page size customization capability, enabling size class calculations to adapt to the target system's page size configuration. [commit](https://github.com/jemalloc/jemalloc/commit/a7f68aed3ef53a194f6b932b92bddd8c84c43de4)
- TSD destruction asserts that the nominal TSD list is empty, detecting residual thread state list issues. [commit](https://github.com/jemalloc/jemalloc/commit/013ab26c8674e07d40098f7385e570c6d8b0dee9)
- Travis CI adds Valgrind build and test tasks, checking memory reads/writes, uninitialized values, and resource leaks. [commit](https://github.com/jemalloc/jemalloc/commit/36eb0b3d77404f389cfddad6675fe1f479e76be7)
- Visual Studio 2015 project adds sc.c and corresponding project filters, enabling the size class module to participate in MSVC builds. [commit](https://github.com/jemalloc/jemalloc/commit/9f43defb6eac30c36dbde25d82e88be23f97309f)
- SC generation process checks that the maximum large size class does not exceed SC_LARGE_MAXCLASS, rejecting size tables beyond the allocator's supported range. [commit](https://github.com/jemalloc/jemalloc/commit/d1a861fa80c66221be8c4d94e51128a4641809da)
- size2index query supports zero-size input, unifying boundary semantics for size 0 between internal lookup and runtime calculation. [commit](https://github.com/jemalloc/jemalloc/commit/4edbb7c64c83aa2059ade469bc798dadf3da194c)
- ticker adds ticker_trytick interface, allowing checking and updating sampling counters without triggering slow processing. [commit](https://github.com/jemalloc/jemalloc/commit/0ec656eb7117127602f295510de694083353f23e)
- rtree adds rtree_szind_slab_read_fast interface, reading size class and slab flag in one operation when the leaf node is known to exist. [commit](https://github.com/jemalloc/jemalloc/commit/5e795297b33f25329a034fd898ee7d80c57b9a8f)
- Adds extent_nfree_sub helper function to atomically decrease the number of free regions in an extent, and the arena reclamation path reuses this count update. [commit](https://github.com/jemalloc/jemalloc/commit/17aa470760cefb3057be746f7022196035f0cfbe)
- configure adds independent options to enable or disable static/shared libraries, and adjusts static and shared target builds accordingly. [commit](https://github.com/jemalloc/jemalloc/commit/4e920d2c9d5aecc9dec7069a0c9736b1f14eead9)
- Implements malloc_getcpu interface on Windows, returning the current CPU index via system processor information for arena binding. [commit](https://github.com/jemalloc/jemalloc/commit/daa0e436ba232d67b832e1b270b13c5061eebfe9)
- Adds Cirrus CI FreeBSD build configuration, compiling jemalloc and running the test suite in a FreeBSD environment. [commit](https://github.com/jemalloc/jemalloc/commit/6910fcb208e2703f72bcbfbd1db22426d02b1e27)
- Travis CI adds --disable-libdl build matrix, verifying jemalloc compiles without libdl configuration. [commit](https://github.com/jemalloc/jemalloc/commit/23b15e764b3d87c8e69a348d60d13e7e44f137b5)
- Adds documentation build to default make targets, so regular builds generate both API and user manuals. [commit](https://github.com/jemalloc/jemalloc/commit/9015deb126d7b2b90ef822cf0183f96abb9b97f9)
- extent_register failure path completes mutex unlock, avoiding other allocation threads waiting indefinitely for the extent lock after registration errors. [commit](https://github.com/jemalloc/jemalloc/commit/59d98919482b2a101c4092428a4c0092abb797a1)

### Refactoring
