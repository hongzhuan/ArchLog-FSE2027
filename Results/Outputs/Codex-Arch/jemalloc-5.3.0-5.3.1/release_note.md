# Release Note

## Important Changes

### Instrumentation & Profiling Layer

- Add double free detection for thread cache in debug builds, with control interface and tests. [commit](https://github.com/jemalloc/jemalloc/commit/36366f3c4c741723369853c923e56999716398fc)
- Add name attribute for arenas, and support reading the name via ctl, stats, and unit tests. [commit](https://github.com/jemalloc/jemalloc/commit/ba19d2cb78176ef715aca461c7a7a7b2afb35772)
- Add experimental.hooks.prof_sample and prof_sample_free hooks, allowing custom profiling sampling and free notifications. [commit](https://github.com/jemalloc/jemalloc/commit/8580c65f81c5252e493da656a448ec3a8571dab7)
- Add header for nonfull slabs output in HPA stats, clarifying the meaning of subsequent statistical columns. [commit](https://github.com/jemalloc/jemalloc/commit/c7805f1eb5b9eadccb9711044e141ff741c09d4c)
- Enable more compiler warnings in CI and fix issues found by the new checks. [commit](https://github.com/jemalloc/jemalloc/commit/da66aa391f853ccf2300845b3873cc8f1cf48f2d)
- Support adding process namespace PID to heap profile filenames, and supplement configuration docs and control interface. [commit](https://github.com/jemalloc/jemalloc/commit/11038ff762a2ba11eec26d3ffb32026424d2ccfe)
- Enable heap profiling on macOS, and update jeprof, system stack backtrace, and related tests. [commit](https://github.com/jemalloc/jemalloc/commit/4b555c11a54d31ba941d996011c7063b2083a12e)
- Add batch allocation and deallocation operations for arena bins, and supplement stats, fork support, and unit tests. [commit](https://github.com/jemalloc/jemalloc/commit/fc615739cbd15dcb4a60c611206d9b8817aab565)
- Add usize parameter to prof_sample_hook_t so sampling hooks get the actual requested size. [commit](https://github.com/jemalloc/jemalloc/commit/bc32ddff2da6e58df90b1762f17519a2c04b26b0)
- Add size limit check when declaring stack arrays, ensuring arrays are smaller than 2048 bytes and adjust related callers. [commit](https://github.com/jemalloc/jemalloc/commit/48f66cf4a22af3b380d4c049f79fb7e820eba3d3)
- Add experimental prefix to hpa_strict_min_purge_interval, clarifying that this option is still experimental. [commit](https://github.com/jemalloc/jemalloc/commit/c7ccb8d7e99a1c3f1ba3cc3e465bc6dd1b0fbe0b)
- Add runtime opt_experimental_tcache_gc option to enable or disable the new tcache garbage collection design. [commit](https://github.com/jemalloc/jemalloc/commit/f68effe4ac0d1ee5cf26fc9c7fc50c88d16bf6ba)
- Add safe frame-pointer stack backtrace implementation, with build options, documentation, and runtime control interface. [commit](https://github.com/jemalloc/jemalloc/commit/edc1576f03d15a22b968828b68a074d9be6e5cc0)
- Make hpa_hugify_sync a configurable option, allowing HPA to synchronously perform huge page conversion and provide ctl/stats support. [commit](https://github.com/jemalloc/jemalloc/commit/0ce13c6fb5ae3bd837f5a7314bd580070bb408da)
- Expose psset page slab set state statistics via ctl and stats, and extend interface and unit tests to cover various counters. [commit](https://github.com/jemalloc/jemalloc/commit/6092c980a6d02b34bc7b3ed0c2ad923d0a5d2970)
- Detect gettid() availability in configure, and have frame-pointer stack backtrace obtain thread ID based on detection result. [commit](https://github.com/jemalloc/jemalloc/commit/17881ebbfd76529904e826f425f3266834cf3a75)
- Implement process_madvise support, and purge pages via this system call when the platform is available. [commit](https://github.com/jemalloc/jemalloc/commit/22440a0207cd7d7c624c78723ca1eeb8a4353e79)
- Make Huge Arena in PAC support transparent huge page mapping and related page operations. [commit](https://github.com/jemalloc/jemalloc/commit/e1a77ec5583702429fbe7c42e7ad37dfd5517cce)
- Add opt.limit_usize_gap configuration value to stats output for easy querying of current size gap limit. [commit](https://github.com/jemalloc/jemalloc/commit/c23a6bfdf6eed78dbe9c2b39a3798d091843a957)
- Add experimental_enforce_hugify control item to enforce HPA huge page conversion and supplement tests. [commit](https://github.com/jemalloc/jemalloc/commit/47aeff1d08806deb4ea8f91535f5470d7de89915)
- Add mallctl to approximately read current active byte count, and supplement stats unit tests. [commit](https://github.com/jemalloc/jemalloc/commit/0988583d7cd67cb9a5327c5e326b56d63f89cf16)

### Extent & Page Management Layer

- Add malloc_open() and malloc_close() reentrancy-safe helper functions, and migrate page file operations into unified I/O handling. [commit](https://github.com/jemalloc/jemalloc/commit/8c2e15d1a5749e50a1f61e216bb5fefc0d71d9b0)
- Add experimental build option to force calling SYS_process_madvise, to verify the system call support path. [commit](https://github.com/jemalloc/jemalloc/commit/852da1be150e9811a3f0ab91302c5d6e9ee62e4f)

### Arena & Metadata Layer

- Use slab bitmap to implement double free detection for debug builds, and extend related tests. [commit](https://github.com/jemalloc/jemalloc/commit/42daa1ac4405a06ed79f68dc2c0ca8c5ad477ecd)
- Set an explicit name for the dedicated oversize arena to facilitate identification of this allocation pool via arena information. [commit](https://github.com/jemalloc/jemalloc/commit/b6125120ac22c2c7e7cd36df114a2b280dcc33e7)
- Add a state check to the double free validation to further confirm that the freed object has not been released repeatedly. [commit](https://github.com/jemalloc/jemalloc/commit/fd60645260b74645cd606bb6a48464890ab39dee)
