# Release Note

## Important Changes

### Cross-cutting / Other Architecture-related Changes

- Clean up extra newlines at the end of log lines in Marvell ML and NIC drivers to avoid outputting extra blank lines. [commit](https://github.com/DPDK/dpdk/commit/8df71650e9fdc6346f09b7a57e86cded7b553152)
- Remove unused abort macro definition in ENA platform adapter header file, cleaning up invalid interfaces. [commit](https://github.com/DPDK/dpdk/commit/917b7c78cee5ea96862fa6351a646bf305a99b6d)
- Add Neoverse N3 SoC model and its processor configuration to Arm Meson configuration, supporting correct compilation parameters for N3 targets. [commit](https://github.com/DPDK/dpdk/commit/cdbcdc5573933d709a95668982c7e31eb9249105)
- Refactor ACC100 and VRB resource release flow, centrally handle queue and device resource reclamation, avoiding omissions or duplicate releases. [commit](https://github.com/DPDK/dpdk/commit/b460b3bbbbe708bc8ac2426c42bd96f18d04c41c)
- EAL adds bitset type and set, clear, find, and traverse operations, providing a common API and test coverage for fixed-size bit sets. [commit](https://github.com/DPDK/dpdk/commit/99a1197647d803e43a676622396ffddf6bf93b62)
- Power management splits ACPI, AMD P-state, CPPC, Intel P-state, and KVM virtual machine implementations into independent power drivers and registers them via operation interfaces, which can be enabled individually as needed. [commit](https://github.com/DPDK/dpdk/commit/6f987b594fa6751b49769755fe1d1bf9f9d15ac4)

### Packet Processing Nodes

- Add basic control path for CN20K NIC PMD, completing device initialization, port configuration, and basic receive/transmit queue integration. [commit](https://github.com/DPDK/dpdk/commit/1bf0fd7e4f5357238e68ab2f53892aad3ba53748)
- Add flow action type validation for CPFL flow engine, rejecting action combinations not supported by the current device or parsing path. [commit](https://github.com/DPDK/dpdk/commit/86126195768418da56031305cdf3636ceb6650c8)
- Fix ixgbe mailbox acknowledgment handling, clearing or retaining request flags based on actual acknowledgment status to prevent message mismatches. [commit](https://github.com/DPDK/dpdk/commit/1f119e4e3c36f954a353028d2ce6879b8adc8289)
- Supplement structures and constant definitions needed for i40e trace buffer reading, enabling debug code to access device trace buffers. [commit](https://github.com/DPDK/dpdk/commit/1f4adfeb5ff94a88efb00b742eff8e63671313b6)
- Add configuration recovery flag query interface for ethdev driver callbacks, allowing drivers to declare that MAC, promiscuous, and all-multicast states need to be restored at startup. [commit](https://github.com/DPDK/dpdk/commit/5e46b176d37787c5536d48b23fff8baf5d674c88)
- ethdev marks return values of query functions such as device info as must-check; when query fails, the result structure content is undefined and callers must not use it directly. [commit](https://github.com/DPDK/dpdk/commit/1ff8b9a6ef248dddebd07a8df7b47f4de9ffab62)
- NTNIC PMD provides flow operation interface and integrates into filter module, enabling hardware flow offload processing. [commit](https://github.com/DPDK/dpdk/commit/ed01e43664aaa98b5660972e9b18645080afcc4e)

- Fix spinlock handling in l2fwd-event, correctly releasing the lock on all exit paths of the event loop. [commit](https://github.com/DPDK/dpdk/commit/1f41deac447d7938198a2acdd1b7862161feef91)
- NTNIC flow API, aging/learning queue, and statistics cleanup remove redundant NULL checks before free. [commit](https://github.com/DPDK/dpdk/commit/165bed470a6d7bad077f178b696f441772182797)
- Add basic framework for Realtek r8169 PMD, including PCI device identification, ethdev initialization, and build configuration. [commit](https://github.com/DPDK/dpdk/commit/9b170cfc6303a9a9a7279149ac6800a72239ad4e)
- r8169 PMD adds log macros, providing unified log categories and output entry points for device debug information. [commit](https://github.com/DPDK/dpdk/commit/491aa390728abbf3527d49c4063ebc16d8a47075)
- r8169 PMD declares Rx/Tx data path function prototypes, providing interfaces for subsequent receive/transmit path implementation. [commit](https://github.com/DPDK/dpdk/commit/1bbe869ee8571aa282a1069c0f2921e13fe58e11)
- r8169 PMD adds port start and stop flows, and manages DASH device state and hardware resources during start/stop. [commit](https://github.com/DPDK/dpdk/commit/b574fb4cc855f4e86659d37ded01e7a218c38865)
- OpenSSL crypto PMD removes redundant NULL checks before release, uniformly handled by release functions that safely accept NULL. [commit](https://github.com/DPDK/dpdk/commit/0e361f5a0ca96d4e228191ceaf800636e7beeea0)
- Remove redundant etc subdirectory in test configuration file directory, consolidating cfgfiles test inputs into the same directory. [commit](https://github.com/DPDK/dpdk/commit/e3052c189f8a6f5bc260b263f3b3be0306751768)
