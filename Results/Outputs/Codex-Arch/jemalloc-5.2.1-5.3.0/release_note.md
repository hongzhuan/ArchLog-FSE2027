# Release Note

## Important Changes

### Platform Abstraction Layer

- Add the hpa_central module, implementing HPA central page allocation management and providing unit tests. [commit](https://github.com/jemalloc/jemalloc/commit/21b70cb540e0f9ff7d7ff20fa21772e96c2215b0)
- Added the hpdata_t type and a standalone module, splitting the HPA page data representation and migrating related operations and tests. [commit](https://github.com/jemalloc/jemalloc/commit/ca30b5db2bbf51b9c4d5aefa2ec87490b7f93395)
- In configure, ensure popcount is available, and add boundary tests for the bit-counting implementation. [commit](https://github.com/jemalloc/jemalloc/commit/a943172b732e65da34a19469f31cd3ec70cf05b0)
- Extracted a function from extent operations that commits and zeroes pages, unifying page commit and initialization handling. [commit](https://github.com/jemalloc/jemalloc/commit/d90655390f5192d53723023667b57453ba23e676)
- Added the PAGE_FLOOR macro to round addresses down to page boundaries, and reused this page-alignment calculation in SEC. [commit](https://github.com/jemalloc/jemalloc/commit/5bf03f8ce5802b90a16b595e962fe4f07ce7fe93)

### Metadata Lookup (Radix Tree)

- Added a ranged flag to edata to identify the range corresponding to this metadata, and updated mapping, extent, and test logic. [commit](https://github.com/jemalloc/jemalloc/commit/12eb888e54572c417c68495fa5be75d9f8402f81)
- Stored the is_head state of extents in rtree leaf nodes, and updated mapping and related assertion checks. [commit](https://github.com/jemalloc/jemalloc/commit/70d1541c5b60ffd3089d312f3e4e534c72738aaf)
- Added rtree_write_range(), supporting writing the same state to multiple leaf nodes at once, and updated emap and tests. [commit](https://github.com/jemalloc/jemalloc/commit/7c964b03524de23eeff7fe203c764c7a0c0977ac)
- Added the experimental.arenas_create_ext mallctl, creating arenas with extended parameters and adding integration tests. [commit](https://github.com/jemalloc/jemalloc/commit/7bb05e04be693b26536dc2335b4d230dacc5d7d2)

### Arena Manager

- Added the arena_get_from_extent helper function, obtaining the corresponding management context based on the extent's arena and simplifying the deallocation path. [commit](https://github.com/jemalloc/jemalloc/commit/3d84bd57f4954a17059bd31330ec87d3c1876411)
- Configure detects whether the compiler supports implicit fallthrough warnings, and enables -Wimplicit-fallthrough when supported. [commit](https://github.com/jemalloc/jemalloc/commit/d01b425e5d1e1ed3d7f7c5571002681469acf601)
- Added a statistics structure for the PA module, and adjusted arena and control interfaces to read page allocation statistics from this structure. [commit](https://github.com/jemalloc/jemalloc/commit/32cb7c2f0b4da21ed2b98b8fde7bba86309d1acd)
- Added the lockedint module encapsulating locked integer counting operations, and migrated arena statistics and their control interfaces to this implementation. [commit](https://github.com/jemalloc/jemalloc/commit/356aaa7dc65d554806287dfa1849a2d47be9b7a8)
- Added pa_extra.c and moved the merged PA statistics implementation into this file, separating page allocator additional functionality. [commit](https://github.com/jemalloc/jemalloc/commit/f29f6090f589bbd1eda92f025e931e449fa9d621)
- Added an interface for batch allocation of objects from new slabs, reducing duplicate processing during arena slab allocation. [commit](https://github.com/jemalloc/jemalloc/commit/49e5c2fe7d35ffdeb2dc767ab7d3c569eb5c6a40)
- Added a zero option to the arena batch allocation interface, allowing callers to request zeroing of batch objects. [commit](https://github.com/jemalloc/jemalloc/commit/f805468957343e0fb02c84c0548eb39f98b9e29c)
- Added the ability to exclude allocations by size for HPA, and covered this behavior through configuration, ctl, and tests. [commit](https://github.com/jemalloc/jemalloc/commit/534504d4a7086084a46ac42c700e9429d2c72fd1)
- Added a per-arena independent oversize_threshold configuration, and supported setting thresholds separately via ctl and tests. [commit](https://github.com/jemalloc/jemalloc/commit/cf2549a149dc27eefef1101500cd9ee743e477a0)
- Added quiescence synchronization before deleting base in arena_destroy, ensuring the base allocator is reclaimed only after concurrent access ends. [commit](https://github.com/jemalloc/jemalloc/commit/862219e461d642d860d2c9ddc122705b031b6d80)
- Allowed SEC to use an arbitrary number of shards, and cached each shard's size to improve shard access. [commit](https://github.com/jemalloc/jemalloc/commit/36c6bfb963e8a36a8918eb841902e006466fb7c2)
- Redesigned hpa_central_t and adjusted HPA shard management, updating arena, PA, and related test interfaces. [commit](https://github.com/jemalloc/jemalloc/commit/d93eef2f405b7c6e2a78f589a5037a26d4bd4d44)
- Implemented a bump allocator for the san module to allocate and reclaim protected objects, and added dedicated tests. [commit](https://github.com/jemalloc/jemalloc/commit/0f6da1257d7182777e47c78f47e0bb2aa28d259b)

### Thread Cache (tcache)

- Cache bin explicitly records low_water as a sentinel state of -1, distinguishing uninitialized low water from actual zero water. [commit](https://github.com/jemalloc/jemalloc/commit/0043e68d4c54a305d84ead95cae27a730540451b)
- Added safety checks to the slow and sampled deallocation paths of sdallocx(), validating the deallocation size provided by the caller. [commit](https://github.com/jemalloc/jemalloc/commit/974222c626b351256f071d18994c70b79d10a627)
- Added the emap module to track extent lock states, and migrated related lock management from extent, arena, and allocation paths into this module. [commit](https://github.com/jemalloc/jemalloc/commit/01f255161c97fac5a64517a0366d59eb8afdeae0)
- Added a tcache GC delay option, allowing configuration of the delay behavior for cache garbage collection. [commit](https://github.com/jemalloc/jemalloc/commit/ee72bf1cfd236d6e076d9d9bdfcb09787016d62b)
- Added a hard upper limit for the tcache maximum size class, and updated documentation and internal configuration. [commit](https://github.com/jemalloc/jemalloc/commit/5e41ff9b740258bddebcbd5575e1670a15f8b1ae)
- Added the SEC small extent cache module, providing a cache implementation and adding independent unit tests. [commit](https://github.com/jemalloc/jemalloc/commit/ea51e97bb893f560c70f42478d67c8159ee09b3d)
- Allowed opt.tcache_max to override smaller size classes, and added configuration notes and boundary tests. [commit](https://github.com/jemalloc/jemalloc/commit/bf72188f80c59328b20441c79861f9373c22bccd)
- Added a batch allocation mode for cache_bin_alloc(), and added corresponding unit tests. [commit](https://github.com/jemalloc/jemalloc/commit/be5e49f4fa09247a91557690cdaef42a82a83d6a)
- Added functionality to detect use-after-free via junk filling and stash caching, with configuration, implementation, and tests. [commit](https://github.com/jemalloc/jemalloc/commit/b75822bc6e5cbbf463c611d8dea32857f8de9d3e)
- Added tcache stash byte count statistics, and output the stashed bytes in the cache via stats and ctl. [commit](https://github.com/jemalloc/jemalloc/commit/e491cef9abcc80de7c2648a0a244a5271848099a)
