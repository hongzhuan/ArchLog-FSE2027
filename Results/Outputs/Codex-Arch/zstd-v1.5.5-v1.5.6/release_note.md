# Release Note

## Important Changes

### Advanced Features

- Add `ZSTD_d_maxBlockSize` decompression parameter to allow callers to limit the maximum block size accepted by the decompressor, and add streaming and fuzzing test coverage. [commit](https://github.com/facebook/zstd/commit/61efb2a047b308b6f0c265e1eae9ca8a062268e4)
- No-magic-number format decompression now falls back to compatible handling when one-shot decompression path fails, and adds streaming test coverage for this format. [commit](https://github.com/facebook/zstd/commit/7d970bd83c2323c5e78b4f15ae850373c70f055d)

### Tools & Applications

- Fix `--mmap-dict` help text, add line breaks for option descriptions and clearly show the bidirectional switch form of `--[no-]mmap-dict`. [commit](https://github.com/facebook/zstd/commit/c28031df8f1809621407b5bc9c4b3e052872409f)
- Add macOS Universal2 fat binary build target to Makefile and add generated universal binary to ignore list. [commit](https://github.com/facebook/zstd/commit/0a794163f4feccf2c408c206f37da5f5b0eab4de)
- Add Lorem Ipsum text generator and integrate into benchmark programs for generating controllable synthetic text samples. [commit](https://github.com/facebook/zstd/commit/d0b7da30e26406c7ece2bf538a70410e80b9de9f)
- Adjust sentence punctuation of Lorem Ipsum generator so generated text includes common sentence patterns like question marks. [commit](https://github.com/facebook/zstd/commit/5a1bb4a4e0aaba722e57cdca46486bc3c6d7e457)
- Extend common compressed file extension list in `--exclude-compressed` and add CLI regression tests. [commit](https://github.com/facebook/zstd/commit/5a66afa0514d0853b0f2a6b5ff3df1ae706f4862)

### Cross-cutting / Other Architecture-related Changes

- Add Win32 build matrix to Windows release workflow, starting to generate and upload 32-bit Windows artifacts. [commit](https://github.com/facebook/zstd/commit/520843d8ffeaed2f57035b7ec3c24d2dbe2e342f)
- Add `ZSTD_LIB_EXCLUDE_COMPRESSORS_DFAST_AND_UP` option to Makefile to exclude double-fast and higher compression strategies in reduced builds. [commit](https://github.com/facebook/zstd/commit/bae174960b4abd8cefadf23f323b2c82829538e6)
- Add compressor trimming instructions to library README, describing how to exclude high compression strategies on demand to reduce library size. [commit](https://github.com/facebook/zstd/commit/cc1ffe0bd6561128f39cc6c673aa75c91a925b68)
- Add options to CMake for compression, decompression, dictionary building, deprecated API, symbol visibility, and compressor exclusion, and pass them to library build. [commit](https://github.com/facebook/zstd/commit/5059618295bc67f4f70eb6f12e6cf57b8d3de141)
- Add guard macros for duplicate inclusion in libzstd.mk to avoid duplicate target definitions when the same Makefile is included multiple times. [commit](https://github.com/facebook/zstd/commit/b69d06a8102f0e04cde0bda2e34984099a0dfba4)
- CMake README adds steps and target examples for integrating zstd into other CMake projects using `FetchContent`. [commit](https://github.com/facebook/zstd/commit/e590c8a0e3b2ecdde5f63d385fa7f9bd759721d3)
- CMake FetchContent example supplements `target_include_directories()` so that Windows and macOS consuming projects can find zstd header files. [commit](https://github.com/facebook/zstd/commit/3c3845b9d88dacbd41cc544abcd3a5f58a120749)
- README adds dependency configuration instructions for introducing zstd via the Bazel module system. [commit](https://github.com/facebook/zstd/commit/98d8ad27a2b2a2fc75e0594bae992824c470f61c)
- Short test CI adds SPARC64 compilation task to verify portability of this architecture. [commit](https://github.com/facebook/zstd/commit/e1ef81a3ae94dad4aa846615fc6e2293b28f50e8)
- Add SECURITY.md explaining security vulnerability reporting channels and how maintainers handle security issues. [commit](https://github.com/facebook/zstd/commit/b6805c54d67f902d32afecc5ca153cd81a77764f)
- Public header supplements undefined state description after compression context errors, requiring callers to reset the context to restore predictable behavior. [commit](https://github.com/facebook/zstd/commit/902c7ec1fe833f7f8d542fe94acba9e3a0a013a1)
