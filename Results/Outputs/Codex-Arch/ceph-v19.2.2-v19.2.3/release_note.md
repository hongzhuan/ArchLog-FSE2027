# Release Note

## Important Changes

### Ceph Metadata Server (MDS)

- Add QA helper functions `is_pg_clean` and wait for PG scrub completion, for scrub tests to scrub only `active+clean` PGs. [commit](https://github.com/ceph/ceph/commit/b333c18f8ea779047142ef8cb55d05303d942166)
- Fixed the issue of missing file descriptors when resetting CephFS directory handle state, setting `fd` in `dir_reset_t::reset()` back to `-1`. [commit](https://github.com/ceph/ceph/commit/73a65c769751207964cff14d0969bd1ad0b53c5e)
- Add MDS admin socket command `dump_export_states`, outputting directory export status and number of frozen waiters, helping locate stages where subtree export is stuck. [commit](https://github.com/ceph/ceph/commit/abeafaa0fe4cc30a9378ad4b29b4c9de059bfc53)
- Add advanced option `mds_log_minor_segments_per_major_segment` (default 16), controlling number of minor segments allowed before creating major segment. [commit](https://github.com/ceph/ceph/commit/58472d2d786e2d50092bac58a2edd81176137c03)
- Fix race condition when libcephfs `ll_sync_inode` prints inode, obtaining inode identifier before logging. [commit](https://github.com/ceph/ceph/commit/c5966a29bbb8a783b9cf68d4fbbdd11cf3d140dd)
- Add file blockdiff operation and concurrent object scan configuration for MDS, to compare file content block differences. [commit](https://github.com/ceph/ceph/commit/98edb020538e383258edf0fae3bea4969d6152a0)
- Integrate file blockdiff API into libcephfs/client, allowing querying ranges of data blocks changed between two snapshots. [commit](https://github.com/ceph/ceph/commit/841ec9467fea99cce7b5685519471f3ae94030a3)
- Add CephFS `BLOCKDIFF` client feature bit, and negotiate this protocol capability when initiating blockdiff requests. [commit](https://github.com/ceph/ceph/commit/d73e904d65a1f7d98633b07abf74fc8bcd658d8a)
- cephfs-mirror uses file blockdiff for regular file transfer, synchronizing only file blocks changed between snapshots. [commit](https://github.com/ceph/ceph/commit/486d742ea27a6bab7bb91b3d1af025f50f4b0d54)

### Object Storage Daemon (OSD)

- Encapsulate MDS log trimming lag judgment into MDLog, and use it for Beacon to generate `MDS_HEALTH_TRIM` warning and its segment count metadata. [commit](https://github.com/ceph/ceph/commit/c9b90664f87941db3cf122f92bbd8e4dd77b6b37)
- Add `btree` to BlueStore allocator configuration optional values, allowing selection of BtreeAllocator. [commit](https://github.com/ceph/ceph/commit/31ed6050a3292adf369551acc9bb1adcf6bb22e9)
- Clean up extra whitespace in Python CephFS binding tests, Dashboard development docs, and cephfs-top. [commit](https://github.com/ceph/ceph/commit/6246a16e5e16bab6a4e7345b6bc55a5f66b5e93e)
- Update ceph-object-corpus submodule, incorporating latest object encoding compatibility corpus. [commit](https://github.com/ceph/ceph/commit/0b54219162a7225d99627949d49ea08d0370ed9d)

### RADOS Gateway (RGW)

- Fix periodic scrub test, using `pg_scrub` helper function to initiate scrub on target PG. [commit](https://github.com/ceph/ceph/commit/0289c4bd7fd4de7380bfd87659ccf9de725145d3)
- RGW Kafka notification topic adds `user-name` and `password` attributes and uses them for SASL broker authentication, while reusing topic TLS connection configuration. [commit](https://github.com/ceph/ceph/commit/5f4cbdd82d5f9cf7e891f005f5c683539deded71)
- RGW notification REST interface rejects Kafka username or password submitted over unencrypted connection, and prefers topic attributes when both topic attributes and endpoint credentials exist. [commit](https://github.com/ceph/ceph/commit/563db184d345f9e307b3b71f3eaf09e2639b7515)
- RGW object write retains written object list when encountering RADOS `ETIMEDOUT`, because write operation may have succeeded after timeout; avoid cleaning up just-written tail objects causing object data corruption. [commit](https://github.com/ceph/ceph/commit/63505589868855553843346e257b74cc7e794e89)
- RGW no longer cancels bucket index operation after RADOS operation timeout, retaining pending index items for bucket listing to recover via disk state check and `cls_rgw_suggest_changes()`. [commit](https://github.com/ceph/ceph/commit/f884b591631db9af58173ba118b35b3e0d8392f8)
- Unify quote format of ETag in RGW S3 responses, conforming to S3 API response conventions. [commit](https://github.com/ceph/ceph/commit/8ea573985c5323021b2e161487a6703786d43d1a)
- Integrate S3 `DeleteBucket` operation into `RGWBucketAdminOp::remove_bucket()`, reusing bucket deletion and parameter handling logic from admin operations. [commit](https://github.com/ceph/ceph/commit/e2a2aba08832709ae82f247c631b3af0b917c012)
- Support forwarding bucket deletion requests from multisite secondary zonegroup, and add configuration option to control empty check for buckets not in local zonegroup. [commit](https://github.com/ceph/ceph/commit/dfe08b55889e5f9d55a118ae8064e5a28b9f83ad)
- RGW STS adds RSA JWT signature verification, constructing public key from token's modulus and exponent and verifying signature. [commit](https://github.com/ceph/ceph/commit/b8720c86c9125b7f14e88571867ace322ae7b90b)
- RGW STS validates OIDC provider `jwks_uri` server certificate fingerprint, rejecting key endpoint connections that fail fingerprint verification. [commit](https://github.com/ceph/ceph/commit/db80d32b0ccecd6fcefc7bf28acf45944d4cc0ca)
- RGW STS allows using system-user signed credentials for request authentication when handling requests forwarded from multisite secondary, while authorizing according to permissions of requested role. [commit](https://github.com/ceph/ceph/commit/c734fc109e2f4665640dd5f22e3c8ca8627e4b83)
- Merge regression test for RGW multipart object copy to itself verifying tail data retention via Squid release branch. [commit](https://github.com/ceph/ceph/commit/e65a0218f99d2949f2ec6d6f633875a2e78f0bc6)

### Monitor (MON)

- CephFS QA mount wrapper adds `removexattr()`, deleting specified extended attribute via `setfattr -x`. [commit](https://github.com/ceph/ceph/commit/318e5831098265405567fea947541bbb1720ccc7)
- RGW notification documentation supplements setting methods for Kafka topic `user-name` and `password` attributes, rules for overriding endpoint credentials, and security requirements. [commit](https://github.com/ceph/ceph/commit/882b506644c87eeb6da4604fdc8cee870b219f96)

### Cross-cutting / Other Architecture-related Changes

- Add external cluster source support for librbd live migration, allowing migration of images from other Ceph clusters while preserving snapshot history. [commit](https://github.com/ceph/ceph/commit/83ab7ae9dc8e9812a70378c4493f6851af2251d8)
- Add NBD stream source for librbd migration, supporting import of external NBD exports via libnbd, and adding dependencies, URI parsing, and tests. [commit](https://github.com/ceph/ceph/commit/5a2c11c579f9a3516c8b532f9d2a79ba2990e03e)
- Sync the CMake project version of the Squid release branch to 19.2.3. [commit](https://github.com/ceph/ceph/commit/1330c0834bdcd59746009d08066181587b05e3b0)

### AsyncMessenger (Messaging & Transport Layer)

- Add a pthread name caching helper method, and set and cache thread names when MDS, mgr, mon, and client threads start. [commit](https://github.com/ceph/ceph/commit/6255143a06c0d6f84c7c3539a810a8a36f8f97b8)
- Set recognizable thread names for worker threads such as MDS Beacon, cache trim, journal, rank, metrics, and purge queue. [commit](https://github.com/ceph/ceph/commit/c3b7dc116a1f40fde1119164c2d55dc81ec67f4c)
