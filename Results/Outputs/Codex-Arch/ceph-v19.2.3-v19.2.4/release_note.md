# Release Note

## Important Changes

### RADOS Block Device (RBD)

- librbd adds the EXCLUSIVE_TRANSIENT lock mode and corresponding policy, which retains the current lock and makes the peer fail immediately when receiving a forced release request. [commit](https://github.com/ceph/ceph/commit/b67e960141d141285a818a23b2d585435fb00dea)

### RADOS Gateway (RGW)

- The RGW Beast frontend adds the ssl_reload configuration, which can reload certificates and private keys at set intervals; reloading does not affect existing connections, and on failure continues to use the previous SSL context. [commit](https://github.com/ceph/ceph/commit/52727bd5694b5d69f007bd2168b86b9219298bd0)
- The RGW notification 2PC queue deducts entry overhead when committing or aborting reservations, avoiding reserved_size leakage and false queue space shortage reports. [commit](https://github.com/ceph/ceph/commit/b97fe168f62274de043b4c15a01d5530760ef159)
- Fixed the reserved_size count drift in the RGW notification 2PC queue, by recalculating total space from reservation records and correcting counts after commit/abort, avoiding erroneous ENOSPC triggers. [commit](https://github.com/ceph/ceph/commit/8f86e0926f4aaf49786f8b35e9b4e478a24a9b73)

### RADOS (Core Object Store)

- When BlueStore deletes an object, it adds the deletion range to the dirty_range of the extent map, ensuring subsequent spanning blob re-slicing can identify and process dirty intervals. [commit](https://github.com/ceph/ceph/commit/d901772ec0600a55bf8058d2fd78f78ef896ba67)

### Cluster Management (Monitors and Managers)

- When the cluster has a filesystem health warning, modifying `max_mds` must explicitly provide the `--yes-i-really-mean-it` confirmation parameter. [commit](https://github.com/ceph/ceph/commit/fe45c051dc7ff829d874ff0f0c1832122cff5e40)

### Cross-cutting / Other Architecture-related Changes

- The v19.2.3 version update of Squid fixes the CephFS test target link dependencies, adds linker compatibility options for libcephfs tests, and includes the RBD client upgrade configuration for Ubuntu 22.04. [commit](https://github.com/ceph/ceph/commit/73c74428ffae86750334a1913cca58c24903cd64)
