# Release Note

## Important Changes

### Allocation Policy & Management Layer

- The configuration script allows the cross-compilation toolchain to specify the nm tool, avoiding jemalloc overriding the toolchain-provided symbol table program. [commit](https://github.com/jemalloc/jemalloc/commit/3f5049340e66c6929c3270f7359617f62e053b11)
- Add a multi-threaded fork unit test to verify the allocator state of threads before and after fork and malloc behavior in the child process. [commit](https://github.com/jemalloc/jemalloc/commit/fb6787a78c3a1e3a4868520d0531fc2ebdda21d8)
- jemalloc adds architecture-related type and word length definitions for m68k, nios2, and SH3, allowing these CPUs to compile via platform configuration. [commit](https://github.com/jemalloc/jemalloc/commit/82d1a3fb318fb086cd4207ca03dbdd5b0e3bbb26)
- Add a mallctl abort_conf unit test to verify the behavior of reading or updating the abort_conf configuration item. [commit](https://github.com/jemalloc/jemalloc/commit/b0825351d9eb49976164cff969a93877ac11f2c0)
- Complete missing field values in rtree thread-specific cache initialization to avoid undefined pointers and flags in the cache structure. [commit](https://github.com/jemalloc/jemalloc/commit/d60f3bac1237666922c16e7a1b281a2c7721863c)
- The configuration script respects the nm program specified by the toolchain, using the target toolchain's symbol tool for link checks. [commit](https://github.com/jemalloc/jemalloc/commit/24766ccd5bcc379b7d518b3ec2480d2d146873ac)
- Explicitly add falls through comments between switch branches in hash.h, indicating intentional continuation to the next case. [commit](https://github.com/jemalloc/jemalloc/commit/56f0e57844bc1d2c806738860bf93e2ccee135b5)
- jemalloc detects at startup whether the kernel supports lazy purge, and selects the deferred reclamation method for extent pages based on the detection result. [commit](https://github.com/jemalloc/jemalloc/commit/0720192a323f5dd2dd27828c6ab3061f8f039416)
- The base allocator allows placing a0 metadata into the transparent huge page region of the third base block, extending metadata THP coverage. [commit](https://github.com/jemalloc/jemalloc/commit/79e83451ff262fbc4bf66059eae672286b5eb9f0)
- The configure stage detects MADV_DONTDUMP and MADV_DODUMP, enabling the page dump control interface according to operating system header definitions. [commit](https://github.com/jemalloc/jemalloc/commit/ccd09050aa53d083fe0b45d4704b1fe95fb00c92)
- The pages library adds pages_dontdump/pages_dodump interfaces, using madvise to include or exclude specified memory pages from core dumps. [commit](https://github.com/jemalloc/jemalloc/commit/bbaa72422bb086933890a125fd58bf199fe26f2d)
- Add a dumpable flag to extent state, recording whether the corresponding memory is allowed in core dumps and updating the flag when state changes. [commit](https://github.com/jemalloc/jemalloc/commit/d14bbf8d8190df411f0daf182f73f7b7786288c4)
- Unregister extent registration records before releasing extents in leak checking, avoiding stale registration entries after leak cleanup. [commit](https://github.com/jemalloc/jemalloc/commit/26a8f82c484eada4188e56daad32ed6a16b4b585)
- Extent hook tests add callback failure and abnormal return scenarios, verifying that the extent allocation path correctly rolls back after hook errors. [commit](https://github.com/jemalloc/jemalloc/commit/6e841f618a5ff99001a9578e9ff73602e7a94620)
- Add a div module that precomputes reciprocal parameters for dynamic divisors to speed up repeated integer division at runtime. [commit](https://github.com/jemalloc/jemalloc/commit/21f7c13d0b172dac6ea76236bbe0a2f3ee4bcb7b)
- Add an emitter module to uniformly output jemalloc statistics and configuration data in text or structured format. [commit](https://github.com/jemalloc/jemalloc/commit/27a8fe6780cb901668489495b2fc302a2d071d8c)
- The emitter's table mode adds support for row-wise output, and adds unit tests verifying that fields and values are arranged in rows. [commit](https://github.com/jemalloc/jemalloc/commit/ebe0b5f8283b542f59cbe77f69e24935ebb5f866)
- Add TUNING.md, explaining how to adjust arena, tcache, dirty decay, and memory retention parameters based on application scenarios. [commit](https://github.com/jemalloc/jemalloc/commit/2e7af1af733144b58e4977f526f11d015d8457b0)

### Cross-cutting / Other Architecture-related Changes

- Add the --disable-initial-exec-tls configuration option to disable initial-exec model TLS for compatibility with restricted dynamic loaders. [commit](https://github.com/jemalloc/jemalloc/commit/a62e42baebe09dc84aaff731faa6ff87fde6bc4e)
- Add ILP32 ABI support to AArch64 configure detection, enabling correct compilation for target combinations with 32-bit pointers and 64-bit registers. [commit](https://github.com/jemalloc/jemalloc/commit/6df90600a7e4df51b06efe2d47df211cba5935a7)
- Add the --with-lg-vaddr configure option to specify the virtual address bit count of the target system and configure the rtree layout accordingly. [commit](https://github.com/jemalloc/jemalloc/commit/63712b4c4e046e9d91807d0e1b5c890c52925379)

### User-Facing Interface Layer

- jemalloc adds a configurable logging facility, allowing selection of log categories via mallctl and output of internal runtime events. [commit](https://github.com/jemalloc/jemalloc/commit/9761b449c8c6b70abdb4cfa953e59847a84af406)
- Add entry and exit logs to core jemalloc functions, recording parameters, return values, and call flow of allocation operations for diagnostics. [commit](https://github.com/jemalloc/jemalloc/commit/e215a7bc18a2c3263a6fcca37c1ec53af6c4babd)
- Log macros support format strings without variadic arguments, allowing call sites to output log messages without additional parameters. [commit](https://github.com/jemalloc/jemalloc/commit/a9f7732d45c22ca7d22bed6ff2eaeb702356884e)
- Add the metadata_thp statistic, reporting the current usage of jemalloc metadata transparent huge pages. [commit](https://github.com/jemalloc/jemalloc/commit/e55c3ca26758bcb7f6f1621fd690caa245f16942)
- Add the arena.i.retain_grow_limit mallctl, allowing querying or setting the growth limit for retained extents in an arena. [commit](https://github.com/jemalloc/jemalloc/commit/e422fa8e7ea749ab8c4783e405c0f4b19ac25db9)
- Add the opt.lg_extent_max_active_fit configuration, limiting the maximum ratio between the size of active extents used to satisfy requests and the request size. [commit](https://github.com/jemalloc/jemalloc/commit/fac706836ffda46759914508b918e8b54c8020c8)
- Add the opt.thp runtime option, allowing explicit enabling or disabling of transparent huge page advice for base pages. [commit](https://github.com/jemalloc/jemalloc/commit/e4f090e8df5adf180662c5eeac2af214f9594de4)
- Add the opt.background_thread_count option to limit the number of background purge threads, and document the configuration method in the manual. [commit](https://github.com/jemalloc/jemalloc/commit/8b14f3abc05f01419f9321a6a65ab9dd68dcebac)
- Support setting extent hooks on uninitialized automatic arenas, and add integration tests verifying that the first allocation uses the new hooks. [commit](https://github.com/jemalloc/jemalloc/commit/3f0dc64c6b8c1fd77c819028013dacbc6d2ad6b6)
- Explicitly mark unused arena parameters and statistics macros as UNUSED to avoid unused parameter warnings under different build configurations. [commit](https://github.com/jemalloc/jemalloc/commit/0fadf4a2e3e629b9fa43888f9754aea5327d038f)
- Add the arenas.lookup mallctl, returning the arena number managing the allocation for a given pointer. [commit](https://github.com/jemalloc/jemalloc/commit/a32b7bd5676e669821d15d319f686c3add451f4b)

### Refactoring

- C++ newImpl splits exception or allocation failure cold paths into separate branches, reducing instruction overhead on the common successful allocation path. [commit](https://github.com/jemalloc/jemalloc/commit/b28f31e7ed6c987bdbf3bdd9ce4aa63245926b4d)
- Extracted arena bin cache operations into a separate cache_bin file, centralizing allocation and deallocation interfaces for bin entries. [commit](https://github.com/jemalloc/jemalloc/commit/f3170baa30654b2f62547fa1ac80707d396e1245)

- Moved bin initialization logic from the arena module to the bin module, centralizing creation of bin locks, counters, and cache states. [commit](https://github.com/jemalloc/jemalloc/commit/a8dd8876fb483f402833fa05f0fb46fe7c5416e1)
