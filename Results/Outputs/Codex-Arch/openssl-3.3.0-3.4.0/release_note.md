# Release Note

## Important Changes

### FIPS Provider

- Added library context level FIPS indicator callback for callers to observe whether operations use unapproved algorithms or parameters. [commit](https://github.com/openssl/openssl/commit/0557d6c62b7d1f46f6f51e0dca87ad9409236164)
- Added FIPS indicator helper functions to track algorithm approval decisions and report indicator status from FIPS Provider. [commit](https://github.com/openssl/openssl/commit/d4848934a61a668d16078f3118786c9a741b7efd)
- Added FIPS indicator for Triple-DES encryption, with installation configuration control and API documentation explaining its approval status. [commit](https://github.com/openssl/openssl/commit/bc43158797a7f8bc36cb736524bf812db7d8635e)
- FIPS Provider added explicit restrictions for RSA X9.31 signatures, with fipsinstall configuration to control this signature mode. [commit](https://github.com/openssl/openssl/commit/07e4d7f4747005e3ce56423182ad047eb05d8e16)
- openssl fipsinstall adds the pbkdf2-lower-bound-check configuration option, which can enable PBKDF2 minimum iteration/strength boundary checking. [commit](https://github.com/openssl/openssl/commit/aa3830c3fc0f087d65a05fd0ea4fc03e26add002)
- FIPS Provider integrates the EdDSA no-digested configuration, allowing the module to prohibit pre-hashed verification according to installation policy. [commit](https://github.com/openssl/openssl/commit/889277effb65b7f276e375cf0176c4c8597f4203)
- FIPS Provider integrates the PKCS#1 v1.5 padding disable configuration, and reads installation policy through a unified parameter name. [commit](https://github.com/openssl/openssl/commit/2c73d92b203dec3dcded29aaf247b19efc15aafa)
- FIPS KBKDF checks derived key input length according to SP 800-131A Rev.2, and rejects derivation when the minimum security strength is not met. [commit](https://github.com/openssl/openssl/commit/ae87c488956c84795fd35cb9cc8024d620cf06c6)
- Adds the no-fips-post configuration option to disable post-installation self-tests of the FIPS module, and documents its effect in the installation instructions. [commit](https://github.com/openssl/openssl/commit/250a7adbea455051da09c24fdb669ef6133e493a)
- FIPS Provider supports configuring signature digest checking, and incorporates the check result into the FIPS indicator status. [commit](https://github.com/openssl/openssl/commit/fc5c86b8c1f986c3692d275a38ed131e4fb67c36)
- FIPS Provider adds Ed25519/Ed448 signature and verification self-tests to comply with FIPS 140-3 self-test requirements for the EdDSA algorithm. [commit](https://github.com/openssl/openssl/commit/5f04124aab4a477d4e58149d8f04871ff7e5ea4b)
- Adds a FIPS indicator for ECDH cofactor handling, making it easier to report whether key exchange uses the approved cofactor mode. [commit](https://github.com/openssl/openssl/commit/05681e0e3e47e0abc5ec3a4c12ddb0afcd66db37)
- Revokes the EdDSA no-digested configuration option of the FIPS Provider, removing the runtime control for this pre-hashing restriction. [commit](https://github.com/openssl/openssl/commit/f1b17245b6b56ad064fe10508d6192262a0a3b15)
- Updates FIPS self-test vectors and execution flow so that signature and algorithm self-tests cover the current EdDSA/FIPS indicator implementation. [commit](https://github.com/openssl/openssl/commit/96de408228031511e38f8b14a9b7af26f988e72d)
- Internal hash table supports lock-free reads; read operations can safely access entries during concurrent updates according to RCU rules. [commit](https://github.com/openssl/openssl/commit/71fe7f09831682e0dafe49e927da195792cff385)
- Adds a FIPS HMAC key length check option, restricting MAC operations whose key material is below the specified security strength. [commit](https://github.com/openssl/openssl/commit/390f00a1e95f241b4a104c323020c7bc90d5e829)
- Adds a FIPS KMAC key check setting, and documents its policy control in the installation tool and algorithm documentation. [commit](https://github.com/openssl/openssl/commit/ea396c7024dec784c76e05d531db41f98788f1e9)
- X9.42 KDF adds a FIPS key length check option, restricting the minimum security strength of derived key material according to module configuration. [commit](https://github.com/openssl/openssl/commit/12d0f0789a3f518581ecada4f3fba899c0b387db)

### Core Microkernel

- RSA-PSS parameter and signature information parsing checks that the digest length is positive before using it, avoiding invalid digest lengths participating in salt length calculation. [commit](https://github.com/openssl/openssl/commit/e582b2b22bcfbf5ed2b38de5fd1417013028614f)
- X.509 name digest calculation first verifies that EVP_MD_CTX_get_size() returns a valid length, avoiding processing the digest buffer with an invalid size. [commit](https://github.com/openssl/openssl/commit/56e63f570bd5a479439bc6f6a2499f6b86ded341)
- DSA signature parameter handling adds a digest context length check, rejecting invalid digest sizes before performing signature or verification. [commit](https://github.com/openssl/openssl/commit/15e06b12ee9df6347433398cb3f732c4458d4218)
- Object store signature handling performs a validity check before reading the digest context length, avoiding invalid lengths participating in signature data processing. [commit](https://github.com/openssl/openssl/commit/18a30b5637cfaed0830183c1572cac76cfa40b4b)
- Object store error path releases allocated OpenSSL buffers, fixing memory leaks during exception handling. [commit](https://github.com/openssl/openssl/commit/99fe4c10664c2287d34145457823edff3782e413)
- RSA signature and verification paths check that the digest size is positive before comparing data lengths, avoiding invalid digest return values being converted to huge lengths. [commit](https://github.com/openssl/openssl/commit/882a387d0dc12afe8612c4d3f6b9cae5c04611d7)
- Enables SHA3 loop unrolling and EOR3 optimization paths for Ampere ARM processors, leveraging their instruction capabilities to accelerate SHA3 operations. [commit](https://github.com/openssl/openssl/commit/e7f1afe4f7e799394684ce86bd98f2445031eb7f)
- SM2 signature checks whether the public key exists before computing the user identifier digest; returns a parameter error when the public key is missing instead of dereferencing a null pointer. [commit](https://github.com/openssl/openssl/commit/d6a8adeccdb8188517c5a84d35b79ef826176472)
- Timestamp response signature checks the validity of the digest context size before using it, avoiding invalid lengths participating in signature construction. [commit](https://github.com/openssl/openssl/commit/f5fde94c54a1ad49663391750fd1b2f47550a4b6)
- FFC parameter generation checks the return value after reading the digest length, avoiding invalid sizes participating in parameter generation. [commit](https://github.com/openssl/openssl/commit/309c7ffd17334a9f9f5b04286892f10a9aca8a2e)
- QUIC stream mapping adds a pending data query interface, allowing determination of whether the receiving stream still has bytes, FIN, or reset status available for reading. [commit](https://github.com/openssl/openssl/commit/26dd6ba070fdc2566c1a51d29e57e55c9ec7c78b)
- Adds the CRYPTO_atomic_store() API, and implements the atomic store interface in lock-free, pthread, and Windows thread backends. [commit](https://github.com/openssl/openssl/commit/7e45ac6891ade57cb0141402745d144c4ce342cb)
- Adds an internal hash table implementation, providing an independent key-value storage structure with query, insert, and delete operations for OpenSSL internal code. [commit](https://github.com/openssl/openssl/commit/cc4ea5e00028e8e0fe3acbf5027497c077f84446)
- Adds ASN.1 types and build registration for RFC 5755 attribute certificates, enabling OpenSSL to recognize and parse attribute certificate objects. [commit](https://github.com/openssl/openssl/commit/7dcee34c8f921ad65277e9a75fca4a7337fbed6d)
- Adds attribute certificate signing and verification APIs, enabling the X509_sign()/X509_verify() paths to handle attribute certificate objects. [commit](https://github.com/openssl/openssl/commit/b97fb22f596bfb528e69402b1bdcdf144a563918)
- Adds support for reading and setting attribute certificate extensions, and exposes corresponding interfaces for applications to inspect or write extension fields. [commit](https://github.com/openssl/openssl/commit/1eeec94f1fd7de60248d1093d5552dc1f05c2fc9)
- Adds support for the IETFAttrSyntax ASN.1 type, enabling encoding, decoding, and reading of such attribute values in attribute certificates. [commit](https://github.com/openssl/openssl/commit/0e8020a45b2f24e85769cd2c66c41f0b7ffa21e4)
- CMP client adds support for crlStatusList requests and crls responses, enabling querying and receiving CRL status information via genm/genp. [commit](https://github.com/openssl/openssl/commit/40a200f9e781381d72d234c886e38bcfce36bbc8)
- Improves the CMP CRL request flow, correctly constructing CRL queries and handling simulated server responses. [commit](https://github.com/openssl/openssl/commit/ee28152e86641e0299fdb3151716bb0451b2bc53)
- Adds a private random range generation function with a fixed top, and uses it for EC/DSA nonce calculation to improve constant-time handling. [commit](https://github.com/openssl/openssl/commit/13b3ca5c998e6db4f7251a56c43541cb1a422bd0)
- Adds a ChaCha20 assembly implementation for platforms supporting only the RISC-V vector extension, and selects this implementation based on build capabilities. [commit](https://github.com/openssl/openssl/commit/03ce37e11729bbe9964bd613c0eed6156b920208)
