# Release Note

## Important Changes

### Cross-cutting / Other Architecture-related Changes

- EAL adds MSVC-compatible structure packing start/end macros, which can temporarily set 1 byte alignment and restore the original packing value. [commit](https://github.com/DPDK/dpdk/commit/fac4bc0d06c98e15788f47da4e08a8cfb2ba942b)
- Remove unnecessary packed attributes on EAL private and trace point structures to avoid unnecessary compact layout. [commit](https://github.com/DPDK/dpdk/commit/5dc68f2be8adea7aad24dc56dad57ec9a3bfe413)
- Add independent enqueue attribute for eventdev ports, allowing applications to query whether the port supports independent enqueue. [commit](https://github.com/DPDK/dpdk/commit/8c565bbebb8f72decbc4af6a69cb76f07bffc472)
- Add more `-march` feature selections for ARM native builds, enabling build configurations to enable CPU-supported crypto and instruction extensions. [commit](https://github.com/DPDK/dpdk/commit/7829776d0abf10315791957febbea6f24d2c723e)

### Input Poll-Mode Drivers (PMD)

- HiNIC driver removes invalid checks on mutex initialization return values in the compatibility layer, initializing mutexes according to DPDK lock interface semantics. [commit](https://github.com/DPDK/dpdk/commit/0745048c415f46cc61259dc3b46c6b87be50ef6d)
- Add driver framework, build configuration, capability list, and maintainer information for the XSC NIC PMD, providing a foundation for subsequent device features. [commit](https://github.com/DPDK/dpdk/commit/3df82f2592897e3b7e5729fe0bff8f17de0ca35d)
- Extend CNXK NIC flow API support to CN20K, enabling this chip to use DPDK flow rule interface to configure hardware flow tables. [commit](https://github.com/DPDK/dpdk/commit/9d29cd6dc87d6c35c52194a5f7a34f2d84140353)
- Remove redundant free of unsuccessfully created objects in the XSC network processor cleanup path to avoid invalid free operations. [commit](https://github.com/DPDK/dpdk/commit/65f56bc68206237f8a8efa07143d97e6f279afcb)
- Remove unnecessary conditional branches from XSC ethdev handling to simplify device state judgment. [commit](https://github.com/DPDK/dpdk/commit/17fa38f4e8180e3caa1735d690ad629abd1f0a9f)
- Enable ENA PMD to support configuring RSS indirect tables of different sizes and update queue mapping according to the table capacity reported by the device. [commit](https://github.com/DPDK/dpdk/commit/923c753a8f51fbedb906736ec0b82cc425ac3b2a)

### Output Transmission and Buffer Management Filter

- Add batch raw alloc/free interfaces for mbuf, allowing callers to bulk allocate or free buffers without going through the regular mbuf management path. [commit](https://github.com/DPDK/dpdk/commit/55624173bacb2becaa67793b71391884876673c1)
- Adjust lock-free stack implementation and build configuration to use compatible atomic operations under MSVC and compile correctly. [commit](https://github.com/DPDK/dpdk/commit/9c2fde3bc2b1b00cfe5385296b6526e9ab07865f)

### Header Parsing and Decapsulation Filter

- Add tunnel packet type parsing in the DPDK network library, identifying tunnel outer and inner protocols and returning the corresponding packet type. [commit](https://github.com/DPDK/dpdk/commit/64ed7f854cf445829b525df7b27ed00a9bcc9b16)

### Action Execution and Hardware Offload Filter

- Add ZSDA compression device PMD framework, build registration, and capability list, providing a driver entry for this hardware to access DPDK compressdev. [commit](https://github.com/DPDK/dpdk/commit/e5852395e0219670b7be4529abdcc709cdad4d16)
- Add statistics counting and query handling for ZSDA compression device, enabling applications to read compression operation statistics. [commit](https://github.com/DPDK/dpdk/commit/132fbfe7f92d3e53804f9af1830eda0a656ca9b8)
- Implement compression transform configuration for ZSDA compressdev, allowing applications to set transform parameters required for compression operations. [commit](https://github.com/DPDK/dpdk/commit/5a3c51bd1d7a272104184052ba684c21ffd3c91b)
- Simplify TXGBE software and firmware synchronization judgment, removing redundant conditions that do not change the synchronization result. [commit](https://github.com/DPDK/dpdk/commit/0d6b122c28b4a3ab4cbb79103f305e49a9edfcae)
- Allow CNXK outbound IPsec security associations to use duplicate SPI, avoiding the driver incorrectly treating outbound SAs with the same SPI as conflicts. [commit](https://github.com/DPDK/dpdk/commit/c7c508ea8ac802d2b29818cd4433f728ded98e65)
- Add basic inline IPsec support for CN20K, configuring security resources and device states required for NIX and CPT linkage. [commit](https://github.com/DPDK/dpdk/commit/0d9e323bacf0ee8b5b0b8dff69a68e40ace2c5b8)
- Add action2 support for CNXK NPC inline flow rules, enabling rules to configure a second set of hardware action fields. [commit](https://github.com/DPDK/dpdk/commit/6f85e39f72c377e0110239bf4ec1f016dbf7de2f)
- Add inline IPsec handling in the CN20K NIC Rx path, allowing received packets to enter the data path after hardware decryption. [commit](https://github.com/DPDK/dpdk/commit/5856f23129bb084e5d5028a736802288bcbb2416)
- Add inline IPsec receive handling for CN20K eventdev and NIC Rx worker, enabling the event path to consume hardware-decrypted packets. [commit](https://github.com/DPDK/dpdk/commit/edd0d5f3c299ab7790d82e3e80aaae51faad857c)
- Add vDPA backend support for virtio crypto PMD, enabling the device to access virtio crypto queues via vDPA. [commit](https://github.com/DPDK/dpdk/commit/a03c2aff6421993ecfedd98cc7549c4492e069a0)
