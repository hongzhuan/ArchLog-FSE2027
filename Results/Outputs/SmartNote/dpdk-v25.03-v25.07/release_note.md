# v25.07
## ✨ feat
- **Breaking and security changes:** Removed ZUC-256 support from the Intel QuickAssist Technology PMD for Gen 3 and Gen 5 hardware due to specification changes. [40d3c24](https://github.com/DPDK/dpdk/commit/40d3c24617673ccbb841c439d1f12aefdd9ef9c4)
- Merged '-l' and '--lcores' EAL options; '-l' now acts as a short form of '--lcores', eliminating separate handling. [1ea3833](https://github.com/DPDK/dpdk/commit/1ea3833e9c4e06cf6693bf6aba3bec545f620e83)
- Prefixed token pop mode enums in the DLB2 driver with RTE_PMD_DLB2_ to prevent namespace conflicts. [e31d467](https://github.com/DPDK/dpdk/commit/e31d4679575571890974730c989aa286cb516398)
- For new NICs (Medford4 and later), link change events no longer provide detailed link information; the driver now separately queries the link status. [ce09d30](https://github.com/DPDK/dpdk/commit/ce09d307e94fa1ccac637c966ae023c7b21dc52f)
- The CNXK GPIO PMD now uses the standard Linux kernel character-based GPIO interface (gpio-cdev) instead of the deprecated sysfs interface and a custom kernel driver. [9a5ce79](https://github.com/DPDK/dpdk/commit/9a5ce79325da04a8ff3ca247d27e5530ca597036)
- Added speculative execution barriers to several scheduling and profile functions to prevent SPECULATIVE_EXECUTION_DATA_LEAK vulnerabilities. [6323f12](https://github.com/DPDK/dpdk/commit/6323f12e497741337e35e8787c6fece0b5c966e4)
- Added secure memory zero function `rte_free_sensitive()` to prevent compiler optimizations from removing zeroing of sensitive data before memory release. [4752753](https://github.com/DPDK/dpdk/commit/47527539d35664be765c996598034ce9b4e1962b), [bd91f4f](https://github.com/DPDK/dpdk/commit/bd91f4f0a044e5e0aa1c297f9b15f565dc0e69ce)
- Removed debug mode restriction, enabling IV for IPsec operations on CN9k. [b8b35df](https://github.com/DPDK/dpdk/commit/b8b35df9924dc6807afe3bacba81d12977c1debb)
- **New drivers and device support:** Added support for Medford4 NIC family (AMD Solarflare X45xx) with full PHY, MAC, and link management
