# v19.2.3
## 🐛 fix
- **Security fix**: Unprivileged users could gain unauthorized access by changing permissions of a root-owned directory to 777. The fix prevents setting mode bits that grant access to directories they do not own, and adds a test case. [#63458](https://github.com/ceph/ceph/pull/63458) The RGW STS now rejects unsupported JWT algorithms during AssumeRoleWithWebIdentity authentication, throwing an error and logging when encountered to prevent security vulnerabilities. [#62137](https://github.com/ceph/ceph/pull/62137) Password values masked with "****" when parameter name contains "password". Endpoint URLs parsed to log only host and user components, preventing broker password exposure. [#60784](https://github.com/ceph/ceph/pull/60784)
- **Breaking change**: Disable the PG autoscaler for pools with mode 'on' before upgrade to prevent PG splitting or merging from delaying the process, which can extend completion time by a day or more in large clusters. [#62379](https://github.com/ceph/ceph/pull/62379)
- **Breaking change**: `mon_cluster_log_level` now controls cluster log verbosity for all external entities (stderr, syslog, graylog, journald), replacing `mon_cluster_log_file_level` and `mon_cluster_log_to_syslog_level`. [#61069](https://github.com/ceph/ceph/pull/61069)
- **Breaking change**: Removes a scale factor that adjusted maximum available space based on the ratio of non-degraded to total object copies. Available space now remains unchanged until OSDs are marked out, providing a more accurate representation. [#62437](https://github.com/ceph/ceph/pull/62437)
- **Breaking change**: CEPHFS error codes switched to standard system error codes using errorcode32_t in MClientReply messages. Custom error codes replaced with POSIX codes; conversion methods updated. [#61994](https://github.com/ceph/ceph/pull/61994)
- **Breaking change**: Removed fast dispatch for client metrics and ping messages, reducing reconnection overhead and enabling faster transition to the up:active state. [#62058](https://github.com/ceph/ceph/pull/62058)
- **Breaking change**: Reverts `url_decode` to push '%' on invalid percent-encoded sequences instead of returning an empty string, restoring backward compatibility. [#64049](https://github.com/ceph/ceph/pull/64049)
- **Breaking change**: Advisory against deploying new cache tiers added to documentation. [#63830](https://github.com/ceph/ceph/pull/63830)
