# v19.2.4
## 🐛 fix
- **Breaking:** The `mon warn on pool no app` configuration option has been moved from the monitor to the manager daemon [#61304]; the crash module is now always enabled and cannot be disabled [#64284]; `mgr_osd_messages` renamed to `mgr_osd_messages` [#63344]; `aws-chunked` removed from Content-Encoding to comply with the S3 specification [#65219].
- **Security:** STS token validation now checks all keys in the JWKS set instead of stopping at the first failure, with a new config option `rgw_enable_jwks_url_verification` [#64936]; SSL context enforced for SMTP_SSL [#66141]; Grafana configuration updated to disable analytics, plugin checking, and public key retrieval [#66210]; msgr2 protocol fixed incorrect allowed connection modes in AuthBadMethodFrame [#65335].
- **Critical data integrity:** Fixed a critical issue in rbd‑mirror where image deletion could occur incorrectly during resync when the remote image is not primary [#64739]; fixed a bug causing an incomplete demote snapshot to set the image to PROMOTION_STATE_ORPHAN after a daemon restart, preventing snapshot sync [#66165].
- Additional rbd‑mirror fixes: unhandled exception in mirrored image usage info bar when setting a non‑existent snapshot [#65492]; updated thrash test task to use `random.uniform()` [#67162]; fixed race condition causing use‑after‑free on image close [#67580]; fixed race condition in UnlinkPeerRequest causing spurious failures when trashing a snapshot [#67582].
- MDS stability fixes: avoids scheduling quiesce operations for non‑head imported inodes [#61857]; fixed snapshot detection to check parent snaprealms, not just the current one [#63019]; fixed a bug where getattr or lookup could cause a lock to become unstable after a rename [#64539]; resolved a deadlock during MDS shutdown by releasing the mds_lock before blocking operations [#64886]; reordered shutdown sequence to keep worker threads active for acknowledging drain requests [#64924].
- MDS correctness fixes: fixed snapdiff result fragmentation in MDS [#65363]; resolved a bug where sessions remained uncleared until MDS restart due to an issue in the import reverse process [#62055]; MDS server skips charmap handler check for internal requests lacking a client session [#64954]; CephFS client’s monclient now subscribes to monmap and config updates by adding authentication during initialization [#66471]; fixed null pointer dereference during retries in request cleanup [#66472]; health warning “pg is stuck peering” is now ignored during Ceph cluster upgrades [#65449].
- MDS admin and diagnostic improvements: new admin socket command `dump stray` for MDS daemon dumps stray directory contents [#62517]; enhanced historic ops command output and error handling by adding `dump_historic_ops_by_duration` and `dump_ops_in_flight` commands [#64842].
- MDS client fixes: resolve caller‑supplied path to inode in statfs and pass to refactored `_statfs` [#65133]; prevents opening a directory for a non‑directory inode, which caused reference leaks and cache cleanup issues [#65289]; fixed undefined behavior by using moved‑from object’s members directly instead of storing references [#66247].
- CephFS troubleshooting documentation updates: clarified recovery roadblocks and best practices for avoiding recovery roadblocks [#64871] [#64903].
- Build system improvements: added linker option to copy DT_NEEDED entries, fixing undefined reference errors on Ubuntu 22.04 [#63720]; brace expansion supported systemd unit directory changes, fixing installation issues [#64013]; containerized builds benefit from npm caching, improved SRPM detection, and fixed file ownership [#65186]; backports several build improvements to the squid branch [#65249]; added support for additional Fedora distributions, Debian Bookworm, Debian 13, and an Ubuntu distribution [#65844]; installs the appropriate compiler on Debian/Ubuntu systems [#66013]; resolved a distutils error [#66707]; fetches release information from the main branch of the repository, with a fallback to local data [#67001].
- Container and deployment fixes: fix for cephadm user’s home directory configuration – no longer assumed to be under /home, uses system‑defined location [#64605]; replaces subprocess calls to udevadm with direct reading of udev data from /run/udev/data, preventing process pile‑up under heavy load [#65302]; fixed memory lock race condition causing hangs during connection shutdown when monitors are shut down with valgrind [#65785]; use `std::atomic<std::shared_ptr<T>>` for monitor addresses member, fixing compiler warning [#66185]; Valgrind suppression entries added for safe memory leaks [#65661] [#67280]; service creation failed when the service name matched the service type – now always built by combining service type and service ID [#66480]; address field in monitor configuration uses legacy string representation instead of full address object for compatibility with older clients [#68323]; set features are applied when adding addresses, properly handling feature flags [#62061].
- Test configuration and reliability fixes: test configurations expect a cluster log message when the `refuse_client_session` flag is set, preventing false test failures [#59688]; granted extra privileges to the cephtool test script to bypass permission errors from root‑owned files [#63026]; increased file sizes from 1MB to 1024MB and reduced file count to ensure synchronization takes longer than one second for accurate timing [#59829]; increased objects from 15 to 90 to ensure at least one object in the tested PG, fixing the scrub duration test [#64455]; backport fix for TypeError when using random.sample with dict.keys() by converting keys to a list [#64747]; replaced direct `radosgw-admin topic list` calls with a helper function `list_topics`, simplifying test code [#64485]; creates a default realm during multisite test script initialization using the `--default` flag [#65273]; ignore “evicting unresponsive client” warnings to prevent false positives when restarting ceph‑mgr during tests [#66126]; added PG_BACKFILL_FULL and low space errors to the ignore list to prevent test failures [#66973]; increased test image size from 10M to 1G to resolve a race condition [#67074]; updated RBD mirror thrash test task to use `random.uniform()` instead of `random.randrange()` [#67162].
- Test query and encoding fixes: replaced json_tree with json_extract in test queries for broader SQLite3 compatibility [#67322]; backward incompatibility checks in the encoding test script skip objects unreadable by older decoders [#67392].
- Added test verifying that the subvolume group name is included in the pool namespace name to prevent collisions between identically named subvolumes in different groups [#64205].
- RGW fixes: removed `aws-chunked` from Content-Encoding to comply with the S3 specification [#65219]; the radosgw package for Debian works with new and old MIME type handling systems [#63725]; pass SSL certificate as extra argument to RGW frontend to prevent automatic addition when already provided [#64084]; raises an exception for YAML files with trailing tabs, preventing silent failures [#64086]; bucket replication disable condition now checks for None instead of truthiness to handle explicit disable attempts [#64776]; fixed zone update REST API to no longer force STANDARD storage class when configuring placement targets [#65620]; bucket ACLs migrate when a user is migrated to an account [#65665]; multipart uploads retrieve object tags by parsing the tagging header at initiation and storing them in object attributes [#66335]; multi‑object delete operations in versioned buckets skip object lifecycle history updates for all but the last object per group, reducing overhead [#65500].
- Monitor fixes: the `mon warn on pool no app` configuration option moved from monitor to manager daemon [#61304]; the `pg_autoscale_mode` output in `ceph osd pool autoscale-status` now consistently shows `false` in both plain text and JSON formats when `no_autoscale` is set [#59443]; updated the `mon_warn_pg_not_scrubbed_ratio` configuration option description to specify it must be set on the Manager [#62551]; the `mon_memory_target` change could be lost if set in the config database while `mon_memory_autotune` remained at its default – now calls `_set_cache_autotuning()` whenever `mon_memory_target` or `rocksdb_cache_size` are modified [#63804]; the monitor now calls `no_reply()` when an OSD alive message is ignored, properly discarding its state [#64509]; grace period prevents false MON_DOWN health warnings for new monitors [#67324]; address field in monitor configuration uses legacy string representation for compatibility with older clients [#68323].
- OSD fixes: `clear_shards_repaired` resets the shard repair count to zero, clearing the OSD_TOO_MANY_REPAIRS health alert [#60567]; fixed performance degradation in BlueStore’s extent map resharding by correcting `dirty_range` for spanning blobs crossing shard boundaries [#66518]; CephPgImbalance alert rule expression fixed to correctly account for device class when comparing OSD PG counts [#66829]; clears daemon health metrics for down and out OSDs, fixing stat output issues [#67527]; fixes usage of `bluestore_volume_selection_reserved_factor` – prints the first RocksDB level not fitting into the fast device by default, corrects reserved factor application [#66838].
- Dashboard fixes: fixed incorrect display of scheduled snapshot dates for RBD block images in the Ceph Dashboard GUI – epoch timestamp was in milliseconds but date conversion pipe expected seconds [#64880]; fixes parsing error in Grafana dashboards for host overall performance by correcting PromQL queries [#64884]; the health popover in the dashboard now displays correctly with health checks data properly passed to the component [#66145]; defines TypeScript interfaces for API responses to improve type safety, grants every role read‑only access to utilization metrics [#62454].
- Locking fixes: fixes a bug in exclusive lock handling where async requests were incorrectly denied with a blocked request error when the lock was not locked [#66627]; corrected the order of offset and length arguments to properly zero the specified range [#61894].
- Memory leak fixes: fixed memory and resource leak in `group_snap_remove_by_record` and `group_snap_rollback_by_record` by deferring image context creation until after all I/O contexts are established [#64621]; fixed a memory leak in the two‑phase commit queue by including overhead in size calculation when reservations are committed, aborted, or expired [#67575].
- cephadm fixes: disable the cephadm mgr module during cluster cleanup to prevent interference with daemon removals [#61905]; fix for cephadm user’s home directory configuration – no longer assumed to be under /home, uses system‑defined location [#64605]; service creation failed when the service name matched the service type – now always built by combining service type and service ID [#66480].
- Performance counter fixes: adds a command‑line argument that includes a unique identifier in the service’s performance counters output and stores it in metadata for easier association [#65588]; `bytes_written_slow` performance counter reported zero with async I/O due to `aio_write()` transferring buffer ownership – now uses a pre‑calculated `x_len` value [#66354].
- NFS Ganesha: `allow_set_io_flusher_fail = true;` added to NFS Ganesha, allowing container startup without permission failures and eliminating the need for `--privileged` [#60360].
- ceph‑exporter service automatically opens its port when firewalld is enabled [#59932].
- Fixed variable name `vrrp_interface` to `vrrp_interfaces` to properly configure multiple interfaces in keepalive setup [#61902].
- Sidecar systemd units stop when the main unit stops, reusing existing stop logic; starting remains automatic [#62593].
- Pending pings are now correctly tracked after an election, even when the quorum feature set is initially empty, preventing incorrect dead reporting [#62924].
- The `sectype` field is now converted to a list if it is a single string, preventing type mismatches [#63115].
- Fixed missing empty lines in docstrings for proper rendering of function metadata by automethod [#64266].
- CephFS subvolume info command includes a `source` field for cloned subvolumes, showing the source snapshot’s volume, group, subvolume, and snapshot name [#64652].
- The kernel client provides debugfs interfaces (if enabled) for diagnosing slow requests; a NEARFULL data pool triggers synchronous writes, slowing performance [#65077].
- Added exception handling to metric parsing to prevent crashes from malformed data – introduced try‑catch blocks at multiple levels [#65228].
- GuardedMap class encapsulates epoch maps with a mutex, providing mutex‑guarded accessor methods for safe concurrent read/write [#64732].
- Copying the data structure before invoking Python callbacks reduces DaemonStateIndex lock hold time, preventing GIL queueing and improving performance [#65462].
- Message encoding in async messenger protocols now only occurs when connection features are set; if features are not set at sending, the message is encoded later when the connection is ready [#65624].
- Removed uninitialized pointer printed by operator<<, preventing garbage output and undefined behavior [#67704].
