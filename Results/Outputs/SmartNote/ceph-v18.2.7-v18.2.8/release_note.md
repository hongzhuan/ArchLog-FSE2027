# v18.2.8
## 🐛 fix
- **Breaking:** CephFS rename now requires the filesystem offline and `refuse_client_session` flag set. Rename is rejected if MDS daemons are up or flag not set. Tests updated with dynamic waits, fail filesystem before rename, and verify online rename fails. Fixed issue where filesystem was not marked joinable before unmounting clients. [#61410](https://github.com/ceph/ceph/pull/61410)
- **Breaking:** Prevents moving an RBD image that is a member of a group to the trash using `rbd trash mv`. Fixes a bug where the "image will expire at" message was incorrectly displayed on failure; now returns immediately with the error code. Introduces a new Python exception, `ImageMemberOfGroup`, for clear error messaging. Moving a group member image to trash is no longer allowed, except during live migration. [#62967](https://github.com/ceph/ceph/pull/62967)
- **Breaking:** Deprecated features: cache tiering (not recommended, may be removed without notice), inline data, and cls_cxx_gather (due to maintenance issues and retry functionality problems). [#64937](https://github.com/ceph/ceph/pull/64937)
