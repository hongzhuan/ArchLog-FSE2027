- Variadic macros now use standard C99 `__VA_ARGS__` syntax instead of the GCC extension with a named parameter before the ellipsis. [fd51012](https://github.com/DPDK/dpdk/commit/fd51012de5369679e807be1d6a81d63ef15015ce)
- Packing macros __rte_packed_begin and __rte_packed_end support MSVC struct packing, which is incompatible with GCC. These macros push and restore pack values to ensure 1-byte packing. __rte_packed_end triggers a compiler warning if no packing was previously pushed, helping identify missing __rte_packed_begin. The patch checking script enforces that __rte_packed_begin is only used after struct, union, or alignment attributes, and that the macros appear in pairs. Using __rte_packed_begin with enums is forbidden. [fac4bc0](https://github.com/DPDK/dpdk/commit/fac4bc0d06c98e15788f47da4e08a8cfb2ba942b)
