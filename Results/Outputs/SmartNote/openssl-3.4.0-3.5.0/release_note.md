# openssl-3.5.0
## ✨ feat
- KEM operating mode is now optional for RSA, EC, and ECX algorithms, defaulting to their only supported mode. The `-kemop` option is no longer needed. [ddd7ecb](https://github.com/openssl/openssl/commit/ddd7ecb04bcea5c13be3c73f3dc1a101087cdf24)
- The OPENSSL_ia32cap capability vector now supports additional CPUID feature bits from leaves 0x7 and 0x24, expanding internal storage to ten 32-bit vectors. The environment variable interface now supports five logical vectors for more granular runtime control. [acc2655](https://github.com/openssl/openssl/commit/acc26552369bb39de6d30737fc30a6bc4f2ebbae)
- Merges QUIC server implementation with a new listener API for accepting connections and managing listeners. Server address validation uses retry packets with token caching and reference counting. Polling API enhanced with blocking support, inter-thread notification, and new event types. Interop test harness supports server-side tests; new RADIX test framework enables multi-dimensional testing. Includes fixes for memory leaks, use-after-free, thread safety, and platform compatibility. Build system and documentation updates accompany these changes. [#26802](https://github.com/openssl/openssl/pull/26802)
- TLSv1.3 now supports multiple key shares. Clients can send key shares for multiple groups, and servers can prioritize groups using an enriched group list syntax (group tuples with '/' and key share indicators with '*'), while remaining backward compatible. Server-side key exchange group selection is extended with `SSL_OP_CIPHER_SERVER_PREFERENCE` to enforce server preference. [d69c014](https://github.com/openssl/openssl/commit/d69c014608acdfa37839d49412e6d6974ac539a0)
- Added support for X.509v3 extensions: timeSpecification [70b17e5](https://github.com/openssl/openssl/commit/70b17e5a00dae537181e2722033f190cc1550139), allowedAttributeAssignments [9598bc1](https://github.com/openssl/openssl/commit/9598bc15e9bcc137182c709057b79aef1d347a06), and aAissuingDistributionPoint [0d8cc7c](https://github.com/openssl/openssl/commit/0d8cc7c69904371c396a6c6eda58fde0201046c2).
- Set provider configuration parameters via command line and API with the new `-provparam` option for key-value parameters. [38a0926](https://github.com/openssl/openssl/commit/38a0926528791762cf8f0f4e3ed0e2f590b894b9)
- Boolean queries against provider configuration are now supported. [e6855e1](https://github.com/openssl/openssl/commit/e6855e1d79088152a39df72cf0e67845095df7e3)
- Added a new provider API for random number generation, including a function and dispatch function. It distinguishes public and private random numbers using appropriate generation functions. [37172e2](https://github.com/openssl/openssl/commit/37172e2ab8377706c6ce5c79e4bc700cff522f6f)
- Dual 1024/1536/2048-bit exponentiation optimization for Intel Sierra Forest CPU using AVXIFMA ISA, improving RSA-2k/3k/4k sign and decryption performance by 1.8x-2.2x. [c18b6f4](https://github.com/openssl/openssl/commit/c18b6f4c52866d5514e53328667e542333d0977a)
- Added ML-DSA support: encoders for text output of public/private keys [d9ffc11](https://github.com/openssl/openssl/commit/d9ffc11939e6d9b3cb7884f2c082f4c96dceb233), X.509 certificate generation via command line [808fccb](https://github.com/openssl/openssl/commit/808fccb721f2fb621c3ffeb789dc4c13f2f37986), and Wycheproof test vectors for signing/verification [20599e4](https://github.com/openssl/openssl/commit/20599e480f3ba783d6554d3e078d08bdd8e92e66).
- Added ML-KEM to the FIPS provider with key generation, encapsulation, and decapsulation, including self-tests for both normal and implicit rejection paths. [ff40a08](https://github.com/openssl/openssl/commit/ff40a08deeb2a24229f5d9074e9a57717a90edf6)
- Reorganized codec code to facilitate sharing with ML-DSA and direct configuration lookups. Corrected documentation to include the 'prefer_seed' parameter; added tests for 'prefer_seed=no' behavior. [5b2d996](https://github.com/openssl/openssl/commit/5b2d996f9145100f5e6d9fbf8ad2488022496931)
- Introduced a symmetric key management system enabling cipher operations with a dedicated key object, supporting initialization via a key handle, import, export, and generation through a provider-based interface. [d46e010](https://github.com/openssl/openssl/commit/d46e010cd266288a5fb8a663f634c62a3990d6a0)
- Added SLH-DSA support: signature verification for SLH-DSA-SHA2-128s parameter set [2f9e152](https://github.com/openssl/openssl/commit/2f9e152d86a750753ea729f8c9d79d764a73f20c), encoder/decoder for all twelve parameter sets [a25bcde](https://github.com/openssl/openssl/commit/a25bcde26a4553af5ffcd698c5d6f504806efc01), key validation [eba0e11](https://github.com/openssl/openssl/commit/eba0e11c39dcacb14da1eda699d528eae829b0a2), and X.509 certificate generation [7389cca](https://github.com/openssl/openssl/commit/7389cca07961871320afeae46d5ed8a45fe23145).
- Support SHAKE as a message digest algorithm in CMS, as specified by draft-ietf-lamps-cms-sphincs-plus-19. [c3d4303](https://github.com/openssl/openssl/commit/c3d43037b460c7a836073713b78e2c536a08714d)
## 🐛 fix
- In FIPS mode, SHA1 is prohibited for Diffie-Hellman and ECDH key exchange, aligning with NIST SP 800-131Ar2. [ed68623](https://github.com/openssl/openssl/commit/ed6862328745c51c2afa2b6485cc3e275d543c4e)
- Reverts an API change to OPENSSL_version(), restoring its previous behavior of returning formatted strings with descriptive labels (e.g., "OPENSSLDIR: ...") instead of bare directory paths. [f4c4674](https://github.com/openssl/openssl/commit/f4c467452694e1211395d17c2c027d99c35ee1e1)
- Control characters in distinguished names are now escaped by default. [2411f9b](https://github.com/openssl/openssl/commit/2411f9b662fa501c9eec257a30a7da0cfc2dc173)
- When a client uses SSL_VERIFY_PEER with Raw Public Keys (RPK), the connection now aborts if X.509 verification fails, instead of completing without verification. [6ae8e94](https://github.com/openssl/openssl/commit/6ae8e947d8e3f3f03eeb7d9ad993e341791900bc)
- Handling of supported groups configuration: having no valid groups is no longer an error. TLS 1.3 will not be usable. Empty group lists are handled gracefully. [a3143c2](https://github.com/openssl/openssl/commit/a3143c24009ab7336d7e477cfb3bc862f50f14d8)
- The QUIC TLS API no longer requires BIOs to be set; now uses NULL BIOs to ensure the custom record layer functions correctly. [c25f078](https://github.com/openssl/openssl/commit/c25f0780a5f4f2fc710f44847ebd1457b9a495c4) [688cea7](https://github.com/openssl/openssl/commit/688cea710de3baea9cf2cde91d274fe447acbf81)
- The SSL library now accepts any key management implementation that supports a given group, rather than requiring it to come from the same provider. [9fdb2a0](https://github.com/openssl/openssl/commit/9fdb2a0c2d58b7f95ceaddd477696afa133c5c36)
- Fixed ML-DSA key handling: removed PCT on import [2b7679b](https://github.com/openssl/openssl/commit/2b7679b16d970f99e76b631b62f51bdeffb14627) and verify t0 matches calculated value [bd8954b](https://github.com/openssl/openssl/commit/bd8954bfe50b3271475099bcb53565bcb1763e81).

- Reverted a previous fix for macOS RCU on Apple M1 processors that used a custom atomic load instruction; no longer needed due to other fixes. [a6f512a](https://github.com/openssl/openssl/commit/a6f512a1e6c1c2e3e1efaad51a6fcf65f260bbb1)
- Fixes a timing side-channel vulnerability (CVE-2024-13176) in ECDSA signature computation. A ~300 nanosecond timing signal when the top word of the inverted ECDSA nonce is zero can be exploited, especially with NIST P-521 curve. The fix uses a fixed-top variant of modular exponentiation for constant-time execution. [63c40a6](https://github.com/openssl/openssl/commit/63c40a66c5dc287485705d06122d3a6e74a6a203)
- EVP_CipherUpdate() behavior regarding authenticated bytes clarified: the number returned varies by cipher. Stream ciphers (ChaCha20, GCM) handle 1 byte at a time; OCB requires one block at a time. Passing unpadded data in a single call is safe. [d15077d](https://github.com/openssl/openssl/commit/d15077d336e4b6144f8a5fdb0c1bb58ca9d3552f)
- Fixed a bug in the s_server application with the -naccept option: the listening socket remained open after accepting the specified number of clients. [113c12e](https://github.com/openssl/openssl/commit/113c12ee8cee2be232a361da277a2ab48807eeed)
- Fixed multiple RCU issues: race condition on ppc64le [fbd34c0](https://github.com/openssl/openssl/commit/fbd34c03e3ca94d3805e97a01defdf8b6037f61c), premature reuse of quiescent points [25f8e2c](https://github.com/openssl/openssl/commit/25f8e2c15b701514b7b2fe652634289b6fb8581f), reverted previous change [65787e2](https://github.com/openssl/openssl/commit/65787e2dc219685c30539c6f60eb6b64b890bf6f), and replaced atomic exchange with mutex for compatibility [7d28456](https://github.com/openssl/openssl/commit/7d284560a0624206356d46a948ab3a0b6f670c0e).
