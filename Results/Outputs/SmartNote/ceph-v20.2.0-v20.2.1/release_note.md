# v20.2.1
## 🐛 fix
- Increased timeout for stopping OSDs under valgrind to prevent cleanup failures. [#68256](https://github.com/ceph/ceph/pull/68256) [#63716](https://github.com/ceph/ceph/pull/63716) [#68895](https://github.com/ceph/ceph/pull/68895) 
- Multi-distro container build now uses a Jinja2 template and Python script instead of Bash. Distribution-specific decisions are resolved at template render time via CI environment variables, producing a clean Containerfile. The Python script derives distribution info from the base image name and handles tagging, building, and pushing.
