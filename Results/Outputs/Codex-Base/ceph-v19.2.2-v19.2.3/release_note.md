# Release Note

## Important Changes

### Ceph Metadata Server (MDS)
- CephFS adds directory charmap configuration, controlling directory name case and Unicode normalization, inherited by subdirectories; can be set via directory vxattr. [commit](https://github.com/ceph/ceph/commit/6d93463db00d1d2a3d0260f2d5c7c49dfc9ab593) [commit](https://github.com/ceph/ceph/commit/2e7426f7ed468e5fa2c686b51a1db3dfb4123a31) [commit](https://github.com/ceph/ceph/commit/74c2501ab035c1396d86b490f6c73530b0dc8e2f) [commit](https://github.com/ceph/ceph/commit/76daedca651079b3f488937a220bd84f38f62317) [commit](https://github.com/ceph/ceph/commit/f83838a71e41c679f4031c3682e6a70e2cecddcb) [commit](https://github.com/ceph/ceph/commit/409525b530adafa75a534bf16caac791bc12b3a6) [commit](https://github.com/ceph/ceph/commit/88e16394186134a788ba622ab90b89a7d213b113) [commit](https://github.com/ceph/ceph/commit/7428697c82bcb9d0a1aa0921ec14cafe8ca193b1) [commit](https://github.com/ceph/ceph/commit/2ff6a6bc93eb59032297bb1c312693eec43192b0) [commit](https://github.com/ceph/ceph/commit/58ad31feb8f4af1f41e65edc8b03fc0b025a1d26) [commit](https://github.com/ceph/ceph/commit/887e8ed078797c521643e3ee523ddbc5493f1c75)
- CephFS `sync` waits for cap release to flush. [commit](https://github.com/ceph/ceph/commit/60ace3d97f953d13d9f5938cd1b639d763640d89)
- CephFS adds file `blockdiff` operation and libcephfs API; cephfs-mirror can use it to transfer changed blocks of regular files, and MDS concurrent scan option controls object scan concurrency. [commit](https://github.com/ceph/ceph/commit/98edb020538e383258edf0fae3bea4969d6152a0) [commit](https://github.com/ceph/ceph/commit/841ec9467fea99cce7b5685519471f3ae94030a3) [commit](https://github.com/ceph/ceph/commit/d73e904d65a1f7d98633b07abf74fc8bcd658d8a) [commit](https://github.com/ceph/ceph/commit/486d742ea27a6bab7bb91b3d1af025f50f4b0d54)
- CephFS client and MDS switch old `CEPHFS_E*` error codes to system error codes, aligning error returns with standard errno. [commit](https://github.com/ceph/ceph/commit/4947033bbb6b3041167ab6860b09e58a58de3aad) [commit](https://github.com/ceph/ceph/commit/fdf95b26ed07a5e666e69709838fea5c316bc818) [commit](https://github.com/ceph/ceph/commit/78ffd61f0b0d6824cfa5b14c803ee61206db1493) [commit](https://github.com/ceph/ceph/commit/f3824ad6cc3ded205dec3b89c801e92839152216)

### Object Storage Daemon (OSD)
- BlueStore multi-label device expansion rebuilds labels for new regions and adjusts checksum and mount flow, fixing label/allocator state after expansion. [commit](https://github.com/ceph/ceph/commit/ec48444fc5db8ae7d785599bc04c840fc5cd2d15) [commit](https://github.com/ceph/ceph/commit/10d4453488bae8008ab40428a20ddcaea0e1ca52)
- BlueStore adds `hybrid_btree2` allocator option and corresponding weight configuration. [commit](https://github.com/ceph/ceph/commit/d5deca013283d0d379f5ccf402170dda0cd59b8d)

### RADOS Gateway (RGW)
- RGW uses actual transport security state to determine HTTP/HTTPS when calculating website redirect and domain URI prefix. [commit](https://github.com/ceph/ceph/commit/1f039419c5136daff56d3fb5c3272c6c749b821f)
- RGW non-primary zone forwarding `CreateBucket` also forwards request body, preserving request data like `CreateBucketConfiguration`, and avoids inconsistency between empty length and actual checksum. [commit](https://github.com/ceph/ceph/commit/526735e33be73bfec0664443b59d49021be097ea)
- Multisite forwarded bucket creation requests preserve valid owner tenant information, avoiding buckets with wrong ownership created by tenant accounts in target zone. [commit](https://github.com/ceph/ceph/commit/597215293442f8d17a56ee52cfd87c3c79f60dea)
- RGW multisite full sync drains started coroutines before returning error when first shard sync fails; also drains after notification stack cancellation, avoiding leftover background tasks. [commit](https://github.com/ceph/ceph/commit/71aa9f65e24ec41c9c2a99dd675fd303fb7cc284) [commit](https://github.com/ceph/ceph/commit/4cfa58be4c41ad6e83f77e7a667c83e90cb17147)

### Monitor (MON)
- `ceph node ls` now excludes destroyed OSDs, avoiding node list continuing to show destroyed instances. [commit](https://github.com/ceph/ceph/commit/6dcf12b3ae714f7c96e0cc43a863dcdb1ada04a9)
