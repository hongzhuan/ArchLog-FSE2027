# Release Note

## Important Changes

### Core Storage Engine Layer

- AIO submit_batch no longer uses the potentially overflowing uint16_t aios_size parameter; instead, requests are submitted in batches based on max_iodepth to avoid crashes from counter overflow during large I/O. [commit](https://github.com/ceph/ceph/commit/82acbb63852f7c9cbd06d39727fd70471393239e) [commit](https://github.com/ceph/ceph/commit/fa775e24cb5ff7511c62a45aabc71faed449b72c)
- BlueStore supports asynchronous manual RocksDB compaction and adds the bluestore_async_db_compaction configuration switch (enabled by default); RocksDB perf counters record run/completion counts and the duration of the most recent compaction. [commit](https://github.com/ceph/ceph/commit/38380a37be659d175fb912ced687ef6ed8d3b8f1) [commit](https://github.com/ceph/ceph/commit/84be701271f341e4019ea2f08db80eceddd975ef) [PR](https://github.com/ceph/ceph/pull/59961)
- Fix issue where CephFS readdir cache callback may continue accessing freed directory objects after getattr returns; returns CEPHFS_EAGAIN when directory is closed. [commit](https://github.com/ceph/ceph/commit/f6e7c9f04a55acb33f59de6f82cfb4b20fdb8a95)
- SeaStore LBA manager allows allocating non-contiguous extents in key order and batch-allocates LBA mappings during remap. [commit](https://github.com/ceph/ceph/commit/a637390b0456d423197754f469d9e5a1d342c4d6) [commit](https://github.com/ceph/ceph/commit/36216493f69d5721de86c24c9b25b99e47f8a38e) [PR](https://github.com/ceph/ceph/pull/58820)
- Crimson SeaStore Onode stores hobject_t so object identifiers are available for Onode and staged fltree management paths. [commit](https://github.com/ceph/ceph/commit/4b6bd5c4cbdd57767ccb98eab38d9d9f40bb1763) [PR](https://github.com/ceph/ceph/pull/58830)
- SeaStore FixedKVNode adds bidirectional association between copy-source and pending destination, and indexes pending copy nodes by transaction and node key. [commit](https://github.com/ceph/ceph/commit/305a4d1e2aa2c418299e3d0ab57fcf59e38eab78)
- Crimson PG recovery advances the iterator after finding unfound objects during primary recovery startup to avoid getting stuck at the same position. [commit](https://github.com/ceph/ceph/commit/c986a9b612596a8d9498919ffb86bba3a89d020a) [PR](https://github.com/ceph/ceph/pull/58958)
- OSD scrub concurrency limit now only exempts operator-initiated high-priority scrub; automatic scrubs such as after-repair and those without valid history still adhere to the max_scrubs limit. [commit](https://github.com/ceph/ceph/commit/a3f16627fde5426b19b932b9ef41c167e029d30f) [PR](https://github.com/ceph/ceph/pull/59020)
- KernelDevice adds a configurable number of asynchronous discard worker threads, and supports runtime increase, decrease, or shutdown of threads; unifies thread update logic and responds to changes in bdev_enable_discard and bdev_async_discard_threads configuration. [commit](https://github.com/ceph/ceph/commit/1239568e18f5f46e0e17910c520febbadb60418e) [commit](https://github.com/ceph/ceph/commit/91b0fe4d51cebb5667f3e58093ecc1346071f1f0) [commit](https://github.com/ceph/ceph/commit/519730b0b11124cad52e23f37bc1c5f059eaefdf) [commit](https://github.com/ceph/ceph/commit/a776b6e9250808be7b8d4ac945352ad0ffe09791) [commit](https://github.com/ceph/ceph/commit/d58c5c861ab80583b6878e5bce759d64b1991561) [commit](https://github.com/ceph/ceph/commit/78a804ce8254d0dbfc6cef09d42b7ef528503ded) [commit](https://github.com/ceph/ceph/commit/aa601fcdc213eda276b82dda16096656d37185e9)
- BlueStore drains the asynchronous discard queue before saving the allocator; graceful shutdown waits for discard completion, while fast shutdown merges incomplete ranges into the allocator to avoid losing freed space. [commit](https://github.com/ceph/ceph/commit/cf861523cf42f034ce4f0b128cc48e100d1bf486) [commit](https://github.com/ceph/ceph/commit/d65eebc478d0a9bd366f3b5cc38fb4c84aa00dc8) [commit](https://github.com/ceph/ceph/commit/1f0031e52dce525dae6769bd4dee381f35aac397)
- Crimson SeaStore/RBM enables checksum offload on NVMe devices that support end-to-end data protection; corresponding paths switch to NVMe read/write and skip CRC computation performed by the device.
