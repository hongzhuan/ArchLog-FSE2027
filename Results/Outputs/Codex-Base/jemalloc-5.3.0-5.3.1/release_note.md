# Release Note

## Important Changes

### Public API Layer

- Provide a compatibility implementation for platforms lacking system `pvalloc`, and detect/take over corresponding public and libc symbols during configuration. ([commit](https://github.com/jemalloc/jemalloc/commit/5b1f2cc5d79672e0d8852da1b705d68a74d22cd4))
- Implement C23 `free_sized` and `free_aligned_sized` entry points, and add public symbol/platform wrapper configuration. ([commit](https://github.com/jemalloc/jemalloc/commit/cdb2c0e02fc303fd56aa525ef63eb71136e62b2d))
- Added: `Expose private library dependencies via pkg-config`. ([commit](https://github.com/jemalloc/jemalloc/commit/ed7e6fe71a193ce24d1409d19d2c792f19af6a21))
- Added: `Expose jemalloc_prefix via pkg-config`. ([commit](https://github.com/jemalloc/jemalloc/commit/ce8ce99a4a969e8dd8644d7382126fbb423d9859))
- Add a build-time switch to disable reading jemalloc configuration from configuration files or environment variables. ([commit](https://github.com/jemalloc/jemalloc/commit/c17bf8b368dd400614a42942c2c31a50bce5c680))
